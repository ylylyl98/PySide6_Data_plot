# Megasweep

[项目首页](../../README.zh-CN.md) · [English](../en/megasweep.md)

Megasweep 是 app 内的原生 Qt Quick 工作区，用于双扫描轴光学数据和标量输运数据。
在左侧选择 **Megasweep**，再选择 **PL、Reflection 或 Transport**。
三个模式分别保留测量文件、背景、参数和显示设置。

## 选择数据

使用 app 的 **Folder…／File…** 或工作区的 **Open file…**。
共享文件选择器支持搜索、光学／Transport 候选筛选和添加外部文件。
默认只展示当前模式所记住目录中的兼容文件，重新打开时定位到已选文件。
三个模式分别记住浏览目录、上次文件和搜索范围，重启后仍可使用；
记住上次文件不会自动读取或计算它。重新打开选择器会清除旧搜索词。

| 搜索范围 | 展示内容 |
| --- | --- |
| Current folder（默认） | 当前目录中的 CSV |
| Include subfolders | 当前目录及其子目录 |
| Entire experiment | 当前实验根目录及其子目录 |

手动选择新 Folder 会优先浏览该目录，同时保留已加载测量。选择其他目录的文件后，
下次 File 从该文件所在目录打开；外部文件不属于已选实验时，其所在目录作为新的实验根目录。

文件分类只检查表头，真正的兼容性在加载时验证；测量列表排除
`Processed Data/` 和 `*_outputs/` 等输出目录。

改变浏览目录不会改变已加载测量绑定的输出目录；切换模式或工作区也不会覆盖
其他模式选中的 CSV。采集程序更新文件后，用 Reload 重新读取。
普通参数修改使用已加载的数据快照，不持续重复读取采集中的文件。

光学 CSV 包含两个扫描坐标列和以 nm 为单位的数值波长表头；Transport CSV
包含标量测量列，保留支持的单位行和采集元数据。坐标或信号列有歧义时，
需要明确选择扫描轴和信号通道。

## 分析流程

- **PL：**自动或手动基线、积分强度、峰能、原始坐标与掺杂／电场变换，
  以及数据中可用的偏置电流／电阻图。
- **Reflection：**背景归一化、峰峰值、定能量和峰位图；参考光谱预览显示
  指定实测坐标处的原始信号、背景和归一化光谱。
- **Transport：**标量二维图、一维曲线和固定坐标线切，以及可用的扫描方向和趟次筛选。
- **光谱切片：**选择原始或变换坐标、固定轴和实测值，逐步浏览切片；
  可按实际能量坐标计算二阶导数，并批量导出一个或两个固定轴系列。

Reflection 的峰峰值图和峰位图默认启用 **Auto Energy Window**，使用本次扫描的完整实测能量范围。
修改 Energy Min 或 Energy Max 会为这份扫描保存手动窗口；重新勾选即可恢复完整范围。
PL 沿用原有初始窗口。自动背景缩放使用单独的参考能窗，其中需要有可用的实测通道。

### Reflection 工作流程

1. 在左侧模式标签下方用 **Open scan…** 打开样品扫描，核对自动识别的 X、Y 列名，再选择波长通道一致的背景文件。
2. **Analysis map** 显示各扫描点的结果。用 **Map quantity** 切换峰峰值、指定能量处的 RC、峰位或可用的电学量。固定能量默认取最靠近实测能区中点的通道，也可以直接输入目标能量。图上方的 **Plot limits** 集中显示 X、Y 和色阶上下限。编辑数值后按 Enter 或移开焦点即可应用。X、Y 各自的方向按钮可立即反向。地图有至少 50 个有效值时，自动色阶采用第 2–98 百分位；小样本或百分位重合时使用实测极值。在 Color 区可选 **RdBu_r**（默认）或 **RdBu**。勾选 **Color → Auto** 会立即更新色阶。
3. 在 **Reference spectra** 中输入 X 或 Y，按回车或移开焦点后，预览会跳到该轴最近的实测值。若有多个匹配点，选另一轴最接近当前位置的点，两个输入框都会显示选中的实测坐标。用 Repeat 可查看同一坐标的重复测量。图中显示该点的样品谱、参考谱和 RC，并标出所选指标。选择匹配的背景后会自动打开此预览。新扫描默认使用实测背景，缩放系数为 1。要为整张扫描估算共同的缩放系数，在 **Background → Normalization** 中开启 **Auto Background Scale**。**Auto-select scale windows** 会在当前校准点的样品与背景强度比中寻找平稳区间，并显示选中的能窗。可核对是否包含宽峰；要手动指定，关闭自动选窗后在 **Advanced reference settings** 中编辑。重新打开扫描时会恢复该文件保存的设置。
4. **Spectral cut** 沿指定方向提取整组光谱。沿 X 时固定 Y，沿 doping 时固定 E-field。使用变换坐标时可选择栅压公式。结果包含容差内的实测点，Previous 和 Next 可切换到其他切片。

**Gate coordinates** 根据当前列名识别顶栅和背栅。两列都无法识别时，启用栅压变换后可用 **Top gate (TG)** 指定顶栅。在 **Doping (D) and E-field (E)** 中选择一组定义：D = TG + r × BG、E = TG − r × BG，或 D = r × TG + BG、E = r × TG − BG。两式共用一个杠杆臂比值 r。地图和光谱切片使用同一组定义。

按扫描名分目录导出时，文件名和图标题都会标出分析量及能量条件，例如 `rc_at_1.65eV.csv` 和 `rc_p2p_1.6-1.7eV.png`。峰位导出也注明找峰、找谷或自动选择。CSV、PNG 和 JSON 完全相同时复用已有文件，内容变化时添加 `_002` 等序号，同名 JSON 记录原始扫描路径。

## Reflection 背景

Reflection 复用 DRR 的背景文件浏览组件，计算遵循 Megasweep 规则。

点击 **Background references** 打开背景选择窗口。列表包含当前浏览目录及子目录
中的 CSV，并排除分析输出目录；**Browse files…** 可添加其他目录的背景。
在背景窗口选择 **Custom、P、N 或 BN**。四组分别保存文件和浏览位置，
切换角色不会清空其他组；当前测量只使用当前角色的一组参考，应用于全部扫描点。
同组内多个文件按下列方式平均，其他角色不参与计算。
选择会直接应用到当前测量，切换测量文件时恢复该文件各组的选择。
背景位置与测量目录独立，改变测量 Folder 不会移动已记住的角色目录。

文件名中的 Pback/Nback/BNbackground 等标签用于筛选和检查明确的角色冲突；
无标签文件可手动指定角色，但仍需通过光谱通道检查。
Custom 不允许将明确标记为不同角色的文件混合平均。旧版单一背景列表保留到
Custom，不猜测分组；如包含多个明确角色，需要重新分组后计算。

| 设置 | 含义 |
| --- | --- |
| All frames equally（默认） | 所选文件中的全部选中帧等权平均 |
| First / last frame | 每个文件取首帧／末帧，再平均 |
| Files equally | 先在各文件内平均，再对文件等权平均 |

首帧／末帧保持原版含义。文件帧数不同时，“全部帧等权”与“文件等权”结果不同。
背景应用前必须验证光谱通道匹配，文件名分类本身不代表兼容。
这里不进行 P+N 重建，也不自动应用 DRR 的拟合背景或 BN 校准。

## 导出与视频

点击右上角的 **Save CSV + PNG** 或按 **Ctrl+Shift+S**，即可导出当前结果。
Megasweep 默认以 96 DPI 导出宽 432 像素的 PNG。拖入 DeckCraft 空白宽屏幻灯片时，整张图宽 4.5 英寸，绘图区为 3 × 2.25 英寸，色条距绘图区右边框 0.05 英寸。编辑并替换幻灯片已有的图片时，DeckCraft 沿用该图片的现有尺寸。

新分析默认保存到测量所绑定实验目录的
`Processed Data/Megasweep/<源文件名>/`。旧会话中的自定义输出目录按分析配置保留；
导出后查看实际输出路径。PNG 使用当前显示范围和色标，CSV 保留数值数据；
JSON 记录处理参数、当前背景角色及实际使用的测量／背景来源。
其他角色的选择作为配置保留，不参与本次计算。如果 CSV、PNG 和 JSON 的内容相同，重复保存会复用已有文件。内容有变化时才生成新版本。

在已连接的 DeckCraft 演示文稿中双击 Megasweep 图片，可以按导出时的背景和分析设置重新打开原始扫描。编辑后点击右上角的保存按钮，即可保存新版并替换幻灯片中选中的图片。在 DeckCraft 按 **Ctrl+S** 保存演示文稿。请将 PNG、CSV 和 JSON 保存在实验的同一 Megasweep 导出目录中，并保留原始测量文件。

光学切片的 **Export video…** 提供坐标区间、步距、播放方向、帧率、尺寸、
色阶和坐标范围设置。支持生成预览、播放／暂停和时间轴定位。
FFmpeg 由 `imageio-ffmpeg` 提供，已纳入应用打包配置。编码在后台执行；
取消批量任务时保留已经完成的导出组。

## 会话和开发

新版配置与原版 Megasweep 会话分别保存。加载源文件时可导入兼容的旧版参数，
不修改原版会话文件；不同路径和模式分别记录。缺失的背景必须重新定位后才能计算。
旧版多图布局和线切表不会完整恢复；导入时会在日志中列出未恢复的设置，
应检查当前参数后重新生成图像。

数值实现来自
[`ylylyl98/Megasweep_data_analysis` 的 `2612f6f`](https://github.com/ylylyl98/Megasweep_data_analysis/tree/2612f6f9c1a0946ab62c9d9b7c221bdcb8f101ff)，
置于 `core.megasweep` 命名空间。界面和状态使用当前 app 的 Quick 架构。

```powershell
.venv\Scripts\python.exe run_quick.py --workflow megasweep
.venv\Scripts\python.exe run_quick.py --workflow megasweep --megasweep-mode Transport --open "transport.csv"
.venv\Scripts\python.exe scripts\check_megasweep_integration.py
```

集成检查使用合成数据和临时配置，覆盖三个模式及导出，并在 `build/megasweep/`
生成截图和报告，不操作实验源文件。
