## 背景工作流与处理顺序

默认原生界面通过 **Background…** 打开设置，来源标签依次为 **Self, BN, P, N, P + N, Fitted**。External 是所选外部参考的处理类别，并不是另一个来源标签。**Advanced tools…** 打开当前来源的工具，**Back to background** 返回来源草稿。**Apply background** 先验证并加载草稿，再更新结果；**Close** 保留已经应用的参考。Qt Widgets 兼容对话框对应的标签包括 **Background settings…**、**Advanced**、**Apply**、**Fixed current background**、**Use background** 和 **Use in settings**。下文在相应协议中保留这些 Widgets 标签；**Group BN**、**Assign to selected** 及详细高级检查器属于相应的 Widgets 工作流，不表示原生面板已提供每个控件。保存草稿与应用背景是不同操作。

Self 提供 **First frame / Last frame**；新草稿默认 Last。更改帧只修改草稿。新 BN/P/N/P + N 参考默认在每个文件内平均全部帧，再对文件等权平均。**Advanced tools… → Reference frames** 保留显式首帧/末帧覆盖。不同门电压条件的帧不是可互换的重复帧，仍须通过背景验证。已保存 P/N 合成背景显示为 **Saved composite · single-frame background**；输出帧选择器不会重新选择原始 P/N 帧，原始选择单独记录。

处理顺序直接影响结果：

| 模式 | 处理顺序 |
| --- | --- |
| External，包括逐测量 BN/P/N 分配 | 每个测量先用其分配的参考校正，再对测量等权平均，最后对整组 DR/R 求导。 |
| Fitted (sample) | 将原始测量对齐到共同实测能量/门电压支撑域，等权平均强度，拟合一个组背景，再计算 `I_mean / B_fit - 1` 并求导。 |
| 一个外部参考含多个来源文件 | 每个文件独立归并帧，再对参考文件等权平均；这与重复测量平均是两层操作。 |

例如 9 个测量使用一个 BN、6 个使用另一个 BN，贡献权重为 9/15 和 6/15。一个批次共用同一 BN 时，先平均原始测量再相除，等价于平均各文件校正后的 DR/R。

打开新 CSV 测量时先检查已保存背景。没有背景则打开设置，不先计算临时 Self 图。取消后测量保持等待状态，通过 **Choose background…** 继续。Reload、返回 DRR 或清空背景不会暗中使用 Self，也不会反复弹出设置。缺失或冲突的已保存参考会报告，Reload 可重试恢复。有效历史参考、显式保留的背景及预计算 DAT/XLSX 图直接加载。基本设置按需延迟初始化预览画布和拟合组件。

通过 **Load CSV** 或测量选择器加载处理过的原始 CSV，会恢复该精确测量选择最新导出的配方，包括帧选择、成员分配、区域参考和拟合设置。显式保留的公共背景优先；普通重载保留后续手工修改。历史恢复在加载工作线程中进行。缺失或不兼容的参考会停止加载并要求审阅，不会回退 Self。同一实验切换组时保留显式候选池与匹配策略，丢弃旧计划及审阅确认并重新匹配；导出历史不会替换候选池。清除背景或切换实验时清空候选池。已冻结合成谱通过完整性和原生网格检查后直接复用，不重新生成，也不要求原始 P/N 输入仍未改变。

**Keep background across groups** 在 CSV 组加载失败或被后续请求替代时仍保留公共参考，并对每个新组重新验证。启用 Keep 后仍可生成 BN 比较供审阅，但不会自动替换此参考。异构 BN 分配和组专属校准 BN 不能固定。没有显式 Keep 或精确历史配方时，切组遵循所选来源类型策略；新 BN 映射等待审阅。

## 外部参考与逐文件分配

原生 Quick 中先选择测量组，再选择 P、N 或 BN。**Common reference** 和 **Match each measurement (recommended)** 两个选项始终显示。新的多文件选择必须明确选择方式；仅选择文件不会改变已有配方。原生 BN/P/N/P + N 设置并排显示可用文件和已选参考。切换来源标签会保留各来源的文件与分配方式；搜索只编辑当前来源草稿。**Show all CSV files**、**Browse files…** 可选其他文件，无须引入新来源类型。单击/双击候选文件添加，复选框切换选择；在已选列表中双击、Delete 或 **Remove** 移除；**Clear all** 同时清除被搜索或视图隐藏的参考。P/N 生成仍使用独立单角色选择器，提供 **Use selected**、**Close**。

文件列表只枚举文件名和时间戳，不读取 CSV 网格或处理历史；改变选择不重新扫描目录。原生 P/N 页在后台加载保存历史，采集详情可另行加载。文件对话框从请求工作流的目录开始，清除以前打开/保存操作留下的文件名。

P-only 和 N-only 参考直接使用。候选排序优先匹配已知采集条件（包括旋转角），同等匹配按新文件优先。同角度且无已知条件冲突的组先展开，其他条件和未知角度仍标注并可展开。文件名完整换行，搜索与异步刷新保留已选路径。Browse 导入在 Apply 时验证。旧 Widgets 内嵌选择器使用一个可搜索列表，不复用测量选择器的 group/files/chosen 分栏与 Add/OK 步骤：公共 BN 单选，直接 P/N 可勾选重复参考文件。

### 匹配选定的 P/N 候选池

原生 Quick 的 P、N 或 BN 中选择 **Match each measurement (recommended)** 并选择候选池。候选池变化在 300 毫秒内合并后于后台匹配。逐测量结果显示背景、时间差、时间来源和需复核的提示；审阅后点击 **Apply matched backgrounds**。未解决的测量须先处理，警告须经确认。已验证的采集 run 和 experiment 身份及兼容条件、网格可用于 P/N 批次一致性检查：逐文件建议与联合时间不一致时提示审阅，不强迫共用背景，也不丢弃测量。时间一致性不证明光谱质量。**Common reference** 是独立选项，固定公共背景也独立于匹配策略。

原生逐测量匹配中的 **Matching conditions…** 列出采集字段，每项可通过 **Allow** 允许差异。默认严格匹配；只勾选允许已知值不同的字段，**Reset strict** 清除全部放宽项。角色、恒定门电压和原生光谱网格要求不能放宽。没有已知条件差异的候选优先，再比较未知条件和时间；允许的差异会显示测量与背景双方的值，须审阅。修改规则会取消旧匹配，清除映射和审阅确认后重新匹配。P/N 和 BN 均可逐测量手动覆盖；BN 覆盖在发布前由工作线程重新验证。

导出元数据在 `background_matching_policy` 和测量分配中记录所选规则、差异及人工分配理由。重新打开精确保存组时恢复规则和实际分配，不重新推断映射。同一实验换组时保留候选池和规则，但须重新匹配、审阅，不沿用旧确认。

Qt Widgets 工作流中，P/N 从 **Match selected background files** 开始。选择 **P only**、**N only** 或 **P+N composite**，再选本组可用的背景文件。匹配只搜索这个候选池；空池等待选择文件，不遍历实验目录。增减文件会自动更新建议，清空可重新开始。**Rematch selected files** 在同一池内重新匹配。**One background for all** 保留公共参考选项，合成生成与保存历史入口仍可用。

检查映射后，可多选测量行，通过 **Assign to selected** 分配一个兼容候选。选择框显示这些行的当前分配；分配不同则指示多个背景。缺失/歧义匹配必须解决，带标记的匹配须在 **Apply** 前审阅。匹配使用采集条件、原生光谱网格及可用时间证据，不生成新 P/N 合成背景，也不判定哪个谱在物理上最干净。每个测量先按各自背景校正，再等权平均。DRR 导出元数据记录分配，可恢复精确测量组的配方。

## 实测 BN 匹配与组内比较

Qt Widgets 工作流中，**Match BN by batch** 自动匹配采集批次，**One BN for all** 显式选择公共参考。摘要旁 **Choose BN manually…** 可直接手选，包括未匹配到结果时。列表只包含实测 BN：同角度优先，其次未知角度和不同角度；其他已知条件、缓存网格兼容性和修改时间用于细排。已知网格不兼容文件排最后且不能接受。标签说明角度/网格状态。排序只读文件名和缓存元数据，不读取测量正文或采集日志。手选在 **Apply** 前仍是草稿；取消保留匹配结果和当前背景。

**Match BN** 搜索当前实验中按名称识别的实测 BN CSV；**Advanced** 可限制为所选候选池。勾选多个 BN 仅限制自动搜索，不平均这些候选，也不直接应用。匹配检查已知样品/位置、采集设置、恒定门电压和原生光谱网格。已验证 capture run/experiment ID，加上匹配的设置/网格，才能定义采集批次。没有已验证 run 的文件保持独立并标为 unverified；同日期、文件后缀或同一建议 BN 都不能证明同批次。

公共候选按全批次采集时间间隔之和评估，并与每个测量各自最近候选核对。意见不一致、时间歧义或参考过旧会要求审阅，不强制以多数选择覆盖全批次。这是时间/一致性启发式，不是光谱信噪比优化，也不证明光学状态未变。如果每个文件已有明确建议，确认批次冲突后应用审阅过的逐文件选择，无须强行共用 BN。任何未解决测量都会阻止 Apply，绝不将它从平均中丢弃。

主结果按 BN 汇总测量数和已验证采集 run 数，并完整换行显示文件名。不同已验证批次若共用同一 BN，可合并紧凑行，但保留 run 数；冲突和未验证批次始终明确显示。**Match details**（有标记时为 **Review details**）展开逐文件配对、时间证据、间隔和警告；折叠后保留简要审阅摘要。条件缺失、不完整日志而使用修改时间代理、间隔超过 24 小时、次优候选差距小于 60 秒，都要求确认。这些是审阅阈值，不是物理置信度。等距离或不兼容匹配仍未解决。BN 请求不会回退到 P/N。每个匹配 BN 使用其全部帧，不合并不同 BN 采集。

Qt Widgets 工作流应用自动映射后，主侧栏 **Group BN** 可在该映射与其中一个兼容 BN 供整组选用之间切换。计算成功即更新 DRR/d2E，无须再 Apply。保持每个测量等权、坐标轴、色限、门电压和 SG 设置。失败或已被替代的请求保留上一个有效结果。覆盖只作用于当前选择；**Auto** 恢复原始映射。原始测量和 BN CSV 不变。

当前活动组的验证结果及能量导数使用私有缓存，最多 3 个选择、96 MiB 数组。再次选择可免加载/求导，但发布前仍检查固定签名。来源/计划、有序测量组、坐标轴或处理设置变化会失效。缓存保存私有副本，显示数组不能修改历史结果；过大结果仍可使用，只是不缓存。

确认过且未改变的映射连同审阅确认保存在应用设置中。测量、BN、时间日志或自动候选变化会失效；旧逐文件匹配策略的批准须重新进行批次审阅。一次请求内重复逐点日志会缓存已解析输出路径，仍执行所有 point/run 与时序检查。有限内存事件索引跨测量选择复用未变日志；读前读后检查文件身份、大小、修改和 change 时间，改变或读取不完整的日志不复用。即使来自索引，也对每次选择验证输出路径歧义、帧数、run 身份和逐点时序。重建计划还可在有限进程缓存中复用完整 gate-profile 检查，先验证文件身份/变更签名；缺失、不完整、改变或取消的检查不缓存。

**Advanced** 中 **Follow the current background type** 在切组时保留类型，新 BN 映射仍待审阅。**Fixed current background** 仅固定公共外部参考；异构分配和组专属校准不能固定。所有所选测量仍等权汇成一个 DR/R，再计算能量导数。摘要显示实际背景类型（BN、校准 BN、P/N、其他外部）及每背景测量数，悬停查看完整映射。保存结果会保存分配，原始 CSV 不变。

<a id="bn-calibration"></a>
## BN 校准及其验证条件

原生入口为 **BN → Advanced tools… → Compare BN references…**，Widgets 为 **Background settings → Advanced → BN calibration**。它为当前测量组单独比较选定实测 BN：原始 BN、有界局部条纹位移、有界局部位移加增益。两个拟合族各产生固定 25%、50%、75%、100% 校正候选。每族只拟合一次未收缩模型，再缩放对数背景校正：

`B_alpha = B0 * exp(alpha * log(Bfit / B0))`

Alpha 不参与内部优化，拟合器不能用增大原始参数补偿较弱校正。零校正就是原始 BN。算法读取原始强度，以仅从原始 BN 建立的固定响应基，对实际生产 D2E 拟合恒定位移/增益。每个训练重复、所选 gate 各自处理后再合并目标，不先平均样品谱，也不对已校准背景反复校正。预览展示候选背景、DR/R、D2E、D2E 改善、DR/R 约束结果和完整报告。同一 BN 通过应用真实能量导数流程，以记录的 SG 窗宽和阶数同时生成 DR/R 与 `d²(DR/R)/dE²`。

### 重复文件、优化目标与非劣约束

显式启用高级自动 BN 比较/应用选项后可在组加载后比较；手工比较默认只产草稿。输入/设置不变可复用保存比较。新比较还要重新拟合弱测试特征、重跑候选选择，可能远慢于一次拟合；它在可取消后台线程运行。只有最终验证前已经选定的候选才能自动应用：拟合、候选选择、最终确认使用分离的重复文件，至少 4 个重复，其中至少 2 个最终确认文件。

D2E 是主目标，留出残差必须改善；DR/R 必须满足声明的非劣界限。DR/R 改善会展示，但并不强制改善。默认每重复 DR/R 残差允许增加量为原值 2% 与 0.00001 DR/R 单位中的较大值，训练重复/gate 的各行也应用同一约束。这是固定操作容差，不是实测噪声底。所有 gate 都检查退化，包括完整能量轴上重叠窗口与校正过渡边缘；还须通过时间稳定性和 BN 不相交半帧敏感性检查。BN halves 要求各参考使用全部帧、帧数为偶数且至少 2；半帧不等于独立采集。证据不足保留原始 BN。当前只比较恒定位移、位移/增益族，不含相位斜率、灵活背景样条或自动 SG 调参。

### 训练带与 SG 带宽

拟合读取训练重复的完整光谱，以保留生产 SG 与重网格真实上下文。只有配置的训练带进入损失，但同一训练重复内其他能量不是独立留出。选择和最终确认使用独立完整测量文件。报告同时记录读取通道与评分通道。**Fit energy ranges (optional)** 可用多个不相交区间显式替换旧训练带；每带独立去趋势，二次趋势不跨间隙连接；空输入保留旧带。报告记录逐带响应秩、带宽、参数一致性诊断，但不据此宣布该区物理可信。新增带应由实验证据决定，不能只因曲线平坦而加入。

训练损失是 BN 投影 D2E 残差能量，显示的留出 D2E 指标则是生产 D2E 二次去趋势后的残差 RMS，两者不同。局部 D2E 防护还检查未去趋势 RMS，避免评分去趋势掩盖人为宽曲率。自动应用要求至少一段连续训练评分区间有足够通道和能宽，容纳一个实际 SG 窗口。过长 SG 足迹可能抑制 BN 响应，同时把弱样品特征扩散到整个训练带。带宽检查失败时只可预览候选，保留原始 BN，不暗中缩短 SG 或改变声明区间。

### 特征影响与候选选择敏感性

每个通过选择集检查的候选，还须通过仅训练数据的特征影响检查，才可参与选择。固定协议在校正及 SG 上下文内取 17 个位置，使用正负 0.0002 对数强度高斯扰动，宽度为 1.5、3 个原生能量间距；扰动对所有训练重复/gate 相同。线性敏感性先筛选全部 68 探针。通过者再围绕 3 个最高风险粗中心细查：位置偏移为 -1、-0.5、0、0.5、1 个原生间距，宽度为 1、1.25、1.5、2、2.5、3 个间距，两个符号。中心裁剪到实测轴并去重后，最多追加 168 个探针，每个都须通过。这只覆盖三个中心的局部邻域，不覆盖粗网格所有空隙。

从粗/细检查中选 3 个探针（含最差 DR/R 和 D2E 响应），实际在扰动训练数据上重新拟合同一未收缩族，再应用同一固定强度，核验线性筛选。各训练 gate 分别与冻结背景所传递信号比较。DR/R 或实际 D2E 最大形状误差超过 5% 即否决。筛选是局部近似，不是保证误差界；有限探针不能证明所有未知特征均被保留。只有两层检查都通过的候选按 D2E 收益竞争，采用确定性族/强度顺序，并要求替换当前选择时改善超过 0.01；因此全强度吸收弱特征时，可能保留较弱有效校正。

最终确认前，3 个声明的高风险高斯训练探针还要重跑两个原始拟合、所有强度、候选资格与完整选择规则。选择谱不变，最终文件在此重跑中物理排除。审计衡量切换族、强度或退回原始 BN 引起的输出变化，不以事后回退掩盖跳变。形状误差超过 5% 则禁止自动应用。这是基于粗/细探针联合风险的有限选择敏感性检查；旧结果没有细查证据须重新比较。它不保证所有峰或选择边界；最终确认只能确认或否决已冻结候选。

### 可信支撑与最终确认

自动应用还要求显式声明可信背景区间，覆盖整个校正支撑域。默认可信区为空，**1.94–2.02 eV** 标为不确定，因此仅 1.98 eV 附近纹波评分更低不能替换原始 BN。可信声明是实验判断，不是从平滑度推断的结论。默认 D2E 改善阈值为 10% 和绝对 0.1 (DR/R)/eV²，每个确认重复都须同时满足。这是操作阈值，不是统计置信水平。最终检查失败保留原始 BN，不在最终数据上另选候选。

保护区同时检查原始 DR/R 与实际全轴导数，因为插值和 Savitzky–Golay 会将局部校正传播出去。这些操作容差及较低残差不能证明物理真值或未知特征保真。改变 SG 会使当前联合验证声明失效，须在新设置下重新比较后才能画导数或配对导出。重验证失败自动恢复原始 BN，不记录会关闭后续自动匹配的手工选择。重开后即使自动拟合关闭，也可后台验证保存证书。旧 DR/R-only、dual-improvement 和早期 D2E-priority 比较仍能预览及恢复原始 BN，但不经新比较不能按当前收缩/选择审计策略激活。

### 存储、复用与恢复原始 BN

比较、来源快照和不可变版本保存在实验目录 `.drr_bn_calibration`。重开恢复设置/报告。激活版本绑定精确测量组、原始 BN、帧、SG 和记录输入；字节改变即失效。回到旧设置可复用精确比较，数值管线变化则须新比较。校准版本禁止固定背景，加载器阻止用于别组或包装成合成参考。**Use original BN** 恢复原始选择并记住决定，防止自动检查再次替换。原始测量和 BN CSV 从不覆盖。

<a id="pn-workflow"></a>
## P/N 选择、版本与已保存背景

原生 **P + N** 主页面提供创建和已保存版本。先选测量 group，再在 P、N 两侧选择原始 CSV。两侧各一个时沿用单对合成：检查自动选出的训练文件，高级设置可手动更改。只有一个样品测量时自动使用该文件，显示 **Single measurement draft**。选中两个重复时使用两者；更多重复且编号可识别时默认选第 1 和第 3 个，其余作为检查文件。原有输入验证仍然生效。重建固定独立使用各原始来源的全部帧。点击 **Generate** 保存历史版本并预览，不自动应用；点击一次 **Apply to current group** 验证并应用当前预览，无须另行 Use in settings。

**多组 P/N 候选：** 任一侧选择多个文件后自动计算逐测量分配，无须切换匹配模式或先逐对合成。两侧数量无需相等。页面摘要显示测量数、P/N 对数和重建任务数；**Review assignments** 展开每个测量的推荐组合、两侧到测量的时间差、P/N 互距及警告。下拉框允许手动换成兼容组合；候选很多时默认显示排名前 25 个及当前选择，可展开所有兼容组合。**Matching conditions…** 允许明确放宽指定条件，严格兼容组合仍优先；角色、原生网格和重建帧数要求不能放宽。条件相同后，按两侧到测量的最大时间差、P/N 互距排序。优先使用完整采集记录；不足时统一使用文件修改时间代理并警告。等分或无时间时保留待选择状态，不按文件名打破歧义。

训练文件按局部段准备：只有采集批次已验证、样品条件及 gate 网格兼容、同一 P/N 对且时间连续的测量才合段，按采集顺序取前两个训练，其余作检查。所选背景采集插在两个测量之间或间隔超过一天时切段；一天仅为审阅规则，不是物理稳定性证书。未选采集事件未获评估。缺少已验证批次时每个测量单独生成 **Single measurement draft**，不跨组凑重复，也不把多个背景平均。

**Generate required backgrounds** 按实际 P/N、训练输入、参数和实现身份逐段生成或精确复用保存版本；可切换预览各背景。审阅并确认分配警告后，**Apply to current group** 一次提交完整映射。失败或取消会保留已经保存的草稿，原应用保持不变，不提交部分新映射。改配、换候选、放宽条件或更换 group 会使旧预览失效。导出记录候选、逐文件配对、时间依据、分段训练和版本；重新打开仅恢复历史映射与记录，不重新授予当前匹配确认。

历史版本在后台自动加载，无须 **Load catalog**；可直接选择已保存版本预览并应用。原始输入改变或缺失时须显式使用保存快照，invalid 版本不能应用。只有当前组未改变、曾显式应用且仍新鲜的版本才预选；仅共用 P/N 对不会为新组自动选择历史版本。通用已保存合成文件匹配仍可使用。Qt Widgets 保留 **Background settings → P/N → P+N composite** 及其原有标签。

P/N 来源选择器按**文件修改时间**排列原始 CSV，并非采集时间。目录按已知采集条件与原生网格识别当前组可用文件，支持任意角度。需自己在两侧选择 P/N；选一侧后，另一侧展示与该文件的时间差帮助挑选，原有时间顺序不变。`_001`、`_002` 等后缀不绑定配对。更改一侧保留另一侧。时间接近只是选择辅助，不能证明采集完成或科学适用。未知条件和冲突仍可在详情中查看。**Advanced** 保留手工浏览、实验生成模式、训练文件覆盖、特征保护范围、导入和强制重生成。手工区间拼接仍可在 **Advanced tools… → Build composite…** 使用。

默认跟随当前测量组。未变组若有显式应用且新鲜的版本则恢复该版本；新组进入创建流程。共用旧 P/N 对不会自动选旧 V66，仍可显式从历史选版本。版本时间按电脑系统本地时间显示，存储时间保留原时区。显式用过的草稿仍按同一草稿恢复；新鲜或可恢复不等于科学认可。复用已审阅 V66 时选保存版本并应用到当前组，无须生成。

没有保存结果时，**Import saved…** 接受已有合成 CSV 及元数据。自动生成仍具实验性，只在点击 **Generate** 时运行，不是通用 V66 生成器。CSV、不可变来源快照、生成元数据和版本索引保存于 `Processed Data/DRR/PN Backgrounds`。**Regenerate new version** 保留旧版本并强制重新拟合 P/N 来源。来源内容、帧归并、参数、算法和声明依赖决定精确复用。旧背景可显式用于其他组，但不认证适用性，也不暗中生成替代版本。

窗口展示 P、N 来源曲线、保存背景及生成/版本控件；浏览时不复制主视图 ΔR/R、d²E 图，也不计算测量图。**Apply to current group** 后在主 DRR 视图以其处理/显示控件检查两张完整图。原生网格不兼容会阻止应用。应用记录测量关联，在 External 中选一个生成 CSV；切组策略决定是否保留该公共参考。验证只准备只读使用草稿，提交关联前检查当前组仍匹配。仅生成、预览、取消均不应用。

**All saved pairs** 可在原始文件缺失时打开历史。输入改变/缺失须显式选择保存快照；重生成仍需原始 P/N。**Import saved…** 将合成 CSV 和元数据注册到所选配对，保留原始来源。复制整个背景存储目录才能保留版本历史和关联。

<a id="pn-general-drafts"></a>
## 实验性通用 P/N 草稿生成器

**Experimental sample-assisted draft**、**Experimental P/N only draft** 均为可选模式，默认不选。样品辅助方法 `pn_sample_assisted_curvature_v1` 在多个能量尺度比较重复样品谱与 P/N，辅助区域来源选择。P/N 提供强度和包络，样品谱与 BN 从不替代它们。移动或不一致的样品结构限制选择证据；来源保护是启发式，共有且歧义的共振仍未解决。这是新的通用草稿，**不是已准备 V66 方法的重放，也不能证明同等科学质量**。

至少 4 个测量文件时，在分析前按显示选择顺序分割：1、3、…用于生成，2、4、…单独检查。更少时全部用于生成，没有独立留出；单个重复不足以支持基于重复的来源选择。界面显示角色。样品须有相同原生能量/gate 坐标及兼容已知采集条件，不假设特定角度、样品名或 gate 数。这里的留出只针对本次调用，不代表以前看过的实验数据是盲验证。

实际训练文件内容、顺序、完整范围子集和生成参数进入背景指纹。样品上下文匹配不覆盖保存版本优先策略。训练改变须显式重新生成；仅检查数据或导数设置改变不改变背景。新样品辅助草稿会将独立全范围诊断保存到 `PN Backgrounds/Evaluations`：先平均原始强度再相除，SG 为 11/21 点、3 阶。统计仅描述，不排名、不自动判通过；仍须在主视图固定处理参数/显示尺度审阅完整 ΔR/R 和 d²E。加载已有版本不重跑检查。BN 可作最终效果对照，绝不作生成模板。

P/N-only 的方法名为 `pn_regional_curvature_v1`，保存的是**待审阅草稿**，不是科学认可结果。它多尺度筛查残差结构，选择 P/N 区域，用平滑过渡连接对数强度曲率，报告不确定区域；不使用 BN 或样品。共有共振可能有歧义、区域强度水平可能改变，两张完整图均须在主视图评估。导入已评估 V64/V66 保留其方法身份和批次来源；新通用生成器不复现完整 V64/V66 研究链。文档记录的这两种通用草稿生成器实测检查未通过联合全范围 ΔR/R 与 d²E 标准；它们与下述原始重建后端相互独立。

<a id="pn-raw"></a>
## 原始数据重建方法

### V66 重建后端

`core.drr_pn_reconstruction.generate_from_files(folder, p_file, n_file, training_files)` 从原始 CSV 重算已采用的来源共振拟合、能量依赖对齐、样品条件分类、区域参考和最终 V66 构建。每侧一个原始文件、使用全部帧，并明确选择恰好两个训练测量文件。它不加载旧拟合曲线、旧来源掩码、保存 V66 或 BN 作为生成输入，评估测量不进入此入口。

返回 `PnGenerationResult`，可通过 `save_composite_background(output_csv, result.document)` 导出，再 **Import saved…** 加载；生成本身不保存、应用或覆盖背景。导出的 CSV 与元数据须放在一起。

后端保留已采用区域配方，包括三个纯 P 区域及第三个区域修复。不支持的几何条件明确报错，不回退到未成功的 raw-PN 草稿。gate 数从输入确定，双重复比较是协议的一部分。P/N 当前要求相同偶数帧数且至少 4 帧。前/后半帧检查复用本次全数据来源拟合与分类，重算各自参考和桥接常数；它们是有条件重复检查，不是独立验证。

历史上两个原始测量组已从原始文件重建，并完成阶段对比、完整范围 ΔR/R、SG 11/21 点检查。V66 数值复现证明本次迁移忠实，不代表每个新 P/N 配对都科学有效。

### 正在验证的自适应与局部方法

同一入口 `method="generalized"` 按当前来源状态与光谱分辨率选择 P/N 修复区，没有固定角度、能带、P 区域数量或指定第几个区域修复。它报告不支持/矛盾区域，不标为干净。原批次完整和条件半帧结果精确复现 V66；但同位置第二次 P/N 采集未通过联合全范围 dR/R、d2E 审阅：选定来源的长尾改变基线，持续条纹差异产生固定竖向结构。

独立实验方法 `method="local_evidence"` 将形状改变限制在来源独有区间和紧凑平滑接缝，每个支撑域外精确保留当前父背景。它消除长尾改变，但在已测原数据上增加固定接缝结构，并使一个确认弱肩峰变浅。数值成功或纹理拟合分数更好不能代替科学认可。这些方法不以 BN 或保存背景为生成输入。

实验 `method="conditioned"` 对有界且无相反独有证据的来源区保留原区域构建。边界区/矛盾区只允许紧凑局部修复，且支撑域不得碰到保留的区域修复。决策按当前来源状态和原生分辨率，无角度/固定能量规则。短小未解决来源证据显式标出。条件半帧采用同一决策、自己的系数。这是独立实验方法，不改变后端默认或应用默认生成。

历史实测审阅中，它精确保留原始 V66，并减少一次重复采集的长尾基线改变；仍有固定带，另一次重复仍有密集条纹失配，因此未通过联合全范围 dR/R、d2E 验收。原始 P/N 共同纹理检查显示，相当一部分重复失配早于桥接构建产生，单改接缝不能解决。

<a id="pn-texture"></a>
## 共同细纹理诊断与有界重建

### 原始 P/N 共同纹理诊断

实验 API `core.drr_pn_texture_compatibility.analyze_raw_common_texture` 接受原始 P/N 帧、两个训练测量和显式 eligibility mask，返回诊断及建议对数背景增量，不保存/应用。只拟合原始 P/N 共同细分量的有界原生像素位移和增益。6 个带 35 meV guard 的能量块检查分别报告完整块与可用子集；同一变换还核对 P、N、各半帧、3 个 gate 组和各训练重复，明确报告 Q4 和中带泄漏。

可用性与共享训练信息使这些检查属于条件检查，并非独立科学验证。`apply_common_fine_delta` 构造显式请求的候选，增量零时精确保留父背景，不沿用过时 curvature/PPoly 元数据。诊断独立于应用生成模式；优化/块预测成功不启用自动重建，也不认证完整 dR/R、d2E 或弱特征保真。

历史冻结实测探针对两个原采集都拒绝校准，精确保留背景。两次重复采集的可用块预测改善，但固定带和完整导数图密集条纹仍阻止联合验收。这些建议未替换保存 V66，也未进入默认生成器。

### 可选有界细校正诊断

`core.drr_pn_texture_support.bound_raw_common_texture` 只消费冻结共同纹理分析，不拟合新参数。它保留独立连续可用区间，保护 Q4/shift 输入窗口和完整 SG21 端点跨度，在支撑段内用 C2 过渡；短片段不变。原 6 块建议规则仍必须通过，且逐块重新检查有界预测与实际覆盖。拒绝时应用增量为零，但保留建议供诊断。来源/导数样条系数具有全局性，这些 guard 不证明导数完全隔离。保存区域记录仅描述校正覆盖，不认证底层背景；端点保留不证明校正有益。此诊断仍独立于应用自动生成。

历史冻结后续检查仅对 49 度重复采集施加非零校正（1340 点中的 763 点）。完整产品检查中以前新增的端点导数偏离已消除，但原固定带仍在。94 度重复在一个必需块内无连续支撑，保留父背景；两次原采集也保留父背景。这些安全回退不是改善，完整背景科学有效性仍未建立。

### `conditioned_bounded` 与版本 2

原始重建 API 提供实验 `method="conditioned_bounded"`：由当前 P/N 帧和两个训练测量重建 conditioned 父背景、来源可用域和共同纹理配准，再给完整背景及条件半帧加有支撑的细增量。检查数据、BN、历史保存背景不参与构建。拒绝增量时精确保留本次父背景。最终采样背景与父背景有独立来源记录，父多项式系数不能当成细校正曲线的系数。

对话框 **P/N reconstruction draft** 使用此方法，为新测量组提供草稿；新鲜且显式应用的关联则打开保存模式。原生 CSV/元数据在原始 P/N、训练输入、协议、实现指纹都匹配时可 **Import saved**，导入仍是草稿，应用另行执行。

当前 `conditioned_bounded` version 2 将未应用的拟合来源分量保留在原生差分残差中。被拒绝用于来源相减的分量不能再经共享对齐项进入另一来源。拟合/来源接受阈值不变；对齐策略进入来源记录和缓存身份。旧版本仍可读，不覆盖、不重标。历史 `v66`、`generalized`、`local_evidence`、`conditioned` 保留旧对齐策略以复现。因此拒绝细增量时保留的是 v2 本次的 conditioned 父背景，而不是独立历史方法的结果。

<a id="pn-features"></a>
## 显式特征保护与局部比较

### 保护真实特征

重建模式启用 **Protect real features**，以 eV 输入区间，并明确选择保留局部形状的原始 **P** 或 **N** 来源。**Add range** 可添加多个区间。新组默认关闭，不预置角度/能区。完整选择进入保存版本和生成键，选该版本时恢复；编辑会使旧预览失效，不暗中重标现有背景。

保护在 conditioned 重建及可选细校正后进行。来源平台向两侧各扩展一个完整名义 SG21 跨度，再用另一跨度把所选原始来源对数曲率混入父背景，之后精确积分曲率。全轴仿射对数对齐最小化总体对数强度变化。平台上保留所选来源的对数线形至多差增益/倾斜，外部保留父对数曲率。**外部强度并非不变**：增益、倾斜、样品 DR/R 幅度可在全谱改变。这样避免短距离强行闭合强度而制造导数峰。

无效区间、支撑达到/超出轴端点、支撑重叠均拒绝。这些边距针对 SG21；其他导数设置须另审阅。半帧检查沿用全拟合几何与全局积分常数，但用各自来源帧和父背景。

固定弱样品共振不能仅因多数 gate 都出现就当背景。保护是显式来源选择，不证明该来源无特征。须在全轴导数和留出测量中审阅弱峰符号、线形与两端过渡邻域。样品仍影响父重建，因此影响积分结果及对齐；样品强度和 BN 不会插入保护来源。平滑曲率混合或恢复一个峰都不证明绝对幅度准确、无导数伪影。比较完整背景、接缝及独立重复，旧版本仍可选。

### 离线局部特征比较

实验离线 API `core.drr_pn_reconstruction.auto_features.analyze_local_feature_sources` 接受原生能量轴、原始 P/N 帧、恰好两个训练重复和显式匹配的当前父背景，返回未保存候选及证据报告；未接入对话框默认生成或保存版本选择。

局部极值即使 SG21 窗口重叠，也保留各自中心、锚点、来源观测和重复对比。相近极值不被认证为独立物理峰，不人为拆分未分辨处理峰。比较将父背景与实际构造的局部 P、N 修改一起排名，包含完整过渡支撑。几何允许时，有争议的固定区域仍获得全部三种数值比较和带符号局部对比，但诊断不授权自动采用；父背景可以获胜。

构建建议重叠时排除它们，不合并特征身份；剩余建议接受组合产品检查，任一声明 guard 失败则一起回退。固定来源歧义仍须审阅。数值 transport 分数和重复离散容差不等于物理真值或置信区间。使用前检查全轴产品、弱固定特征、接缝和留出重复。API 不保存、应用或认证背景，数组形状验证也不能建立所传父背景的来源/帧/测量来源信息。

可选离线 `construction_mode="compact_bounded"` 在相同来源选择防护下比较约束局部修改。它用紧凑五次样条拟合所选来源的对数曲率差；原生网格支撑外背景精确等于父背景，对数校正至二阶导数闭合，连续强度比限定 `[1 / 1.05, 1.05]`。这些工程约束可能使目标来源无法拟合。

候选必须在请求区间、平台和整个支撑域满足预先声明的相对曲率 RMS 误差预算 0.50，近零目标改用舍入级绝对检查。数值构造成功但此检查失败的候选仍可见，却不能建议采用。增益界和误差预算均不认证物理准确度。全轴导数仍可将改变带出原生支撑域，过渡伪影需单独审阅。默认仍为 `"integrated_curvature"`，现有 Generate 与保存背景行为不变。

<a id="pn-review"></a>
## 科学审阅与区域报告

审阅应围绕拟研究特征。分析范围外的残差结构本身不构成拒绝局部使用的理由。检查目标范围内主分支、弱特征、线形及重复性，包括基线和导数邻域。先在完整原生轴计算导数，再查看局部。固定结构不自动等于背景伪影。

**历史个案：** 回顾性 YZ383 审阅支持对 1.58–1.89 eV 中已观测主特征作有条件定性使用，1.98 eV 附近不确定结构单独保留。这些样品专属范围不是生成参数，也不是别的数据默认值。弱特征绝对幅度和小导数纹波仍需逐测量解释，峰符号不变不足以证明定量准确。

P/N 对话框 **Region details** 读取保存的来源段、过渡、区域/紧凑修复、未解决证据及可选校正覆盖。有界重建把基础构建与可选细校正分开显示；缺失记录明确标出。文件新鲜度、网格检查、保存、选择背景均与当前测量的科学审阅分离。切换版本先清除旧区域报告，再载入新报告。

<a id="pn-app"></a>
## 应用内原始数据重建与缓存

适配层冻结原始 P/N、已解析训练测量、完整网格设置和实现身份。其他所选测量只作检查，不进入拟合。在 **P+N composite** 中两侧各选一个匹配原始 CSV，按 **Generate**。训练重复从当前组自动选：有编号时按编号排序取第 1、3 个；只有两个则两者；无编号文件保留选择顺序。只有一个测量时自动进入独立版本的 `conditioned_single` 路径。摘要显示文件，提示显示完整路径。**Advanced → Choose sample repeats manually** 可覆盖，不扫描其他组、不按峰排名、不改变拟合；相同输入复用同一保存结果。

**单测量草稿** 使用一个文件的完整 gate 扫描，不复制成两个重复。至少需要 3 个严格有序 gate 行、21 个能量点，P/N 各至少 4 帧且帧数相同、为偶数，原生光谱网格一致，数据为有限正强度。分类使用 3 个 gate 组的一致性、gate 间离散程度和条件 P/N 半帧差；这些只是条件证据，不能估计跨测量漂移或独立样品重复性。输出使用 conditioned 父背景，不执行需要双重复证据的 bounded texture 校正。固定样品共振仍可能与背景混淆，应在主视图检查 dR/R、d2E 和目标峰邻域。报告、缓存和保存版本记录单测量方法及局限；数值成功不代表科学验证。输入不足或不支持的区域仍会明确报错，不自动改用其他方法。

当前原始协议要求 P/N **All frames**、匹配原生网格、相同样品 gate 行、相同偶数帧数且至少 4 帧。独有来源校正的固定支撑若与相反证据、另一请求支撑或延后短岛冲突，则保持未解决，而不终止整个生成。来源选择阶段保留它们的控制权重与背景；后续渲染和可选纹理校正仍遵循各自规则。报告记录延后区域/原因，结果始终为草稿。

成功生成会保存并预览草稿，不应用背景；原生 **Apply to current group**（Widgets 为 **Use background**）仍是独立显式操作。下方进度区显示完成阶段、当前操作、已用时，忙时可 **Cancel generation**。阶段耗时不定，不是剩余时间预测。仅保存并成功载入预览后才显示完成。取消保持窗口打开，已保存草稿留在历史。

每个新组须在两种产品中审阅目标特征、基线邻域和重复性。功能可用不代表任意 P/N 对通过验证。V66 等旧版本仍在历史；完整 dR/R、d2E 在主视图检查，背景对话框仅保留背景预览。

P/N 来源准备使用有界进程缓存，键包含完整 P/N 数组/帧顺序、原始文件内容、光谱列和实现身份。只换两个训练重复可复用来源拟合，但重算样品相关区域、完整/半帧渲染及有界纹理校正。P/N 或实现变化失效；重启清空。完全相同请求也可能复用保存结果。**Regenerate new version** 绕过两种复用。进度与保存执行报告标注复用和阶段耗时。固定来源归属滤波器每阶段只算一次，不逐候选重算；帧数、网格、拟合选择、检查不变。

<a id="manual"></a>
## 手工区间背景与自动建议

原生 **Advanced tools… → Build composite…**（Widgets **Background settings → Advanced → Edit background**）可从 p back、n back 等参考的干净区域创建可复用背景，不必先选测量。添加来源，为每个来源选首帧/末帧/全部帧，将叠加来源谱与加粗组合结果比较。拖选或输入范围，再指定来源；未指定能量使用默认来源。Undo 恢复前一修改。已有 X-range 配方也可打开。

**Save as…** 写入单帧背景 CSV 及 `.metadata.json` 配方，不改主视图。**Use in settings** 返回预览，**Apply** 按所选切组策略应用。普通原始来源 X-range 配方可直接应用，生成或冻结快照必须先保存。打开保存合成背景可再次编辑。**Edit selected P/N background** 将版本复制成独立手工草稿，保留父来源信息，但不冒称原重建方法或科学验证。

配方内冻结来源谱使原始文件移动后仍可重选区域；改变来源帧选择仍须原文件。复制/移动背景时 CSV 与配方须一起保留，两者均受临时来源清理保护。来源谱须共享原始有序网格。手工分配直接切换，编辑器报告接缝跳变，不暗中缩放来源；重载仍保留导数边界。

### Auto suggest 与短缺口重建

**Auto suggest** 在所选原始参考中筛查局部/宽峰和谷，再从实测样点提出区间。参考须在角度、曝光等条件下兼容；网格相同不足以证明兼容。**Keep manual intervals** 保留现有分配。**Reconstruct short gaps** 可选且默认关闭：只有干净来源窗口及两侧比较带都支持时，才估计慢包络并保留实测精细干涉纹理；单纯平滑桥不被接受为背景。纹理支撑缺失/矛盾则区间未解决。

估计、未解决、不支持区间有不同斜线填充和审阅摘要；特征分数低不证明参考无特征。保存前审阅，Auto suggest 不保存/应用。Undo 恢复完整前一配方。保存配方含原始快照、生成结果、来源选择和诊断区间；重开仍标注估计，导数尊重其边界。

### 区间与导数规则

同一 **Edit background** 页以 eV 区间分配来源。当前 External 为未指定能量的默认来源。添加来源后选首/末/全部帧，再拖选或输入区间并分配。一个来源含多个文件时，选帧后文件等权平均。检查组合预览，再 **Use background**；取消保留主配方。

区间不得重叠或超出实测光谱；含下端点、不含上端点，唯独以光谱最大值结尾的区间包含最后样点。每个背景须与测量具有相同原始有序波长网格。边界处直接切换，不重标强度、不交叉淡化。各背景区间内分别计算一阶、二阶及混合导数，切换旁约半个有效 SG 窗口留空；过短区间在该导数产品中留空。原始 ΔR/R 保留每个实测点。配方与全部来源进入导出元数据，并随历史恢复。

**Fixed current background** 在切测量时保留公共手工配方，仍对新谱验证。若组内逐测量配方不同，编辑前须先选公共外部默认参考。

<a id="fitted"></a>
## 样品拟合背景与峰保护

**Fitted (sample)**：选原始 CSV，在背景设置选 Fitted 并 Apply；也可先配置拟合预览/峰保护。首次使用在平均原始强度的每个 gate 上结合 35、70 meV 特征筛查估计峰保护。移动峰只排除其所在 gate 的数据，不把扫过整条能带从所有 gate 中排除。共享包络与逐 gate 强度/倾斜在这些掩码下交替拟合。

**Fit / view background…** 显示实际应用背景、平滑包络、当前 gate 保护及原谱叠加。取消勾选 **Automatically protect peaks at each gate** 会将全部自动区域的并集保留为手工保护，再输入 eV 共振区间（如 `1.56 1.64; 1.69 1.77`）或启用 **Drag to protect a region**。**Fit preview** 检查后 **Use in DRR** 应用。自动保护随来源变化适应，手工配方保留明确区间。宽/弱特征仍可能需要手改。未检测到窄特征时附审阅提示应用平滑拟合；背景支撑不足则停止。

该模式在保护区外拟合对数强度的稳健共享三次样条，每个 gate 配增益与线性能量倾斜。先将所选原始测量对齐到共同实测能量/gate 支撑域并等权平均强度，再给平均拟合一个背景，计算 `I_mean / B_fit - 1`，之后才应用 SG 平滑/导数。成员缺失或改变导致整组失败，不暗中少算文件。不用 BN，不额外减暗。原始强度必须有限且正，保护后须有足够背景支撑。峰外残差好不证明保护峰下背景准确，应比较不同保护/平滑选择。

<a id="fitted-texture"></a>
## 共享细纹理、周期预测与条纹参考

### Correct shared fine texture (learned outside peaks)

**Correct shared fine texture (learned outside peaks)** 从未保护数据估计弱乘性光谱响应。至少 12 个 gate。每个能量处，把可用未保护 gate 按顺序分低/高两组，各至少 6 个且占扫描 15%，并要求局部一致。每条谱先在实测能量坐标上以 35 meV 范围去趋势再汇集，只用未保护样点；保护值不进入局部趋势或纹理汇集。不完整窗口至少要 10 个锚点及稳定二次拟合，支撑不足就排除，不插值。这样移动峰挡住固定半扫时仍可保留其他支撑。

模板从每 gate 保护区外学习，随后在有支撑能量应用到所有 gate，包括该能量被峰保护的 gate。无支撑处不校正，过渡平滑衰减，不改变 SG 求导窗。取消勾选并 **Fit preview** 可与仅平滑包络比较。**Shared texture correction (%)** 展示所加响应，**Texture coverage** 同时显示应用权重（0% 无校正，100% 完整模板）及未保护 gate 比例，灰区不校正。覆盖不是置信分数；仅凭本样品不能可靠判定无支撑区固定条纹的来源。

弱固定样品特征可能与仪器响应不可区分，应手工保护或关闭校正。强自动检测固定峰仍受保护。关闭周期预测时，不跨缺支撑区外推拟合纹理。

### Predict fringes across protected gaps (validated only)

这是共享纹理的可选扩展，默认关闭。**Max components** 将局部拟合限制 1–5 分量（初始 3），验证可选择更少。局部模型尝试能量、波长、像素坐标及恒定/缓变频率；频率界按原生光谱间距确定，包括掩码/留出时。

通用模型须预测两段连续且至少 34 meV 宽的带；若失败，固定单频能量模型须通过四个预设测试：两段至少 12 meV 中心带、两段至少 24 meV 外带。每带还须覆盖请求缺口及至少两个相位周期。所有模型只从未保护训练样点学习，每个测试重新选频，且两个可用 gate 组预测必须一致。单频回退通过时仍保留通用失败报告。超出验证支撑的缺口不变。

保留完整支撑的共享纹理，接受的预测补足缺失/渐弱覆盖，然后归一化并用现有 SG 求导。这些校正从平均强度学习并应用到平均强度，使用包络拟合同一个背景。

检查器报告是否实际增加校正、增加覆盖和拒绝原因。覆盖是应用权重，不是不确定度，也不证明特征来自仪器。应关闭预测比较，保护已知样品特征；d2E 残差较小不足以证明峰保真。样条/多项式比较中的 **Envelope held-out RMS** 只评估平滑包络，与周期预测验证分离。模板、拟合缓存、导出保留选项、验证报告及实际分母，不覆盖原始测量。

### Fringe reference

可显式选择同一样品位置和光路的原始 CSV 提供参考；**Browse** 选文件，**Clear** 关闭，默认空。恒定 gate 的重复帧单独保留。它只提供弱细纹理，平滑包络仍由样品决定，不额外减暗，且必须启用共享纹理。

样品/参考能量网格必须精确相同；参考自身峰保护及独立半帧必须支持校正。共享纹理缺口最多 25 meV，两侧连续验证带各至少与缺口同宽。两带及各自向两侧平移一像素的版本，须通过全部 6 次仅训练校准：振荡残差比不超过 0.4、相关不小于 0.9。保护的样品值不参与校准。失败区保留共享纹理及已单独验证周期预测；选文件不表示成功。

接受的参考纹理仅在共享覆盖不完整处优先于周期预测。检查器报告实际应用，保存元数据保留验证、路径和 SHA-256 指纹。编辑/移除参考使复用失效；跨电脑移动后须选择新路径。

## 拟合背景导出、模板、诊断与缓存

**Save both** 还将实际唯一组背景矩阵及拟合参数写到 `Processed Data/DRR/Fitted Backgrounds`，包含实际纹理、逐 gate 保护、全部输入成员身份、先平均后拟合的处理顺序，并在 DRR 元数据中链接。

**Save template / Load template** 为类似条件复用命名配方。模板只存保护/模型设置，不存拟合强度；保护作用于平均强度。旧手工逐文件保护在组中取并集，自动模式从平均重新生成 gate 局部掩码。加载模板替换组保护。

平均原始强度在所有 gate 筛查正/负窄特征。**Check average** 后台拟合/检查当前组，用一行列残差、审阅提示、最差 gate。**Add suggested regions** 合并建议，不缩小已有保护；应用前重拟合并检查。筛查是启发式：35 meV 局部二次、随能量变化的噪声阈值、跨 gate 重复或强单 gate 特征、5 meV 边距；可能漏宽/弱共振。`Checked` 不证明峰下背景。诊断进入导出元数据。

**Compare methods** 用相同保护叠加平均强度的稳健样条与对数强度 2–4 阶多项式。可切换两者二阶导数，使用对话框打开时捕获的相同 SG 设置。报告背景差异及最多 3 个留出锚带、最多 9 个代表 gate 的预测误差。比较不自动改变组选定方法，也不建立保护区内不确定度。

紧凑拟合/质量检查缓存在应用重启间保留，键含来源身份、强度/坐标内容、轴、完整拟合设置和算法版本。gate、色限、导数视图改变不重拟合。用户应用缓存目录中的可丢弃缓存上限 256 条/128 MiB；缺失、损坏、不可写则重新拟合。原始 CSV 不变；命中也可能花时间读取/解析。

逐 gate 增益/倾斜按有界批次拟合，每个 gate 保持独立稳健权重和收敛状态；掩码中位数批量计算，避免逐 gate Python 调用。组加载显示拟合进度和当前文件，Run Log 记录各文件耗时及是否复用拟合缓存。

本会话还按数据内容/相关参数复用独立于保护的特征筛查及留出验证评分。仅修改保护时，把已有特征候选与新区域重新核对；改变 SG 重算导数并复用仍有效评分。每个审阅缓存最多 128 个小结果/2 MiB，不保留原始谱。临时留出拟合只计算预测，完整拟合保留全 gate 质量检查。

## 如何理解历史证据

上述 V64/V66、YZ383、49 度/94 度、原采集/重复采集结论描述特定历史数据的评估，既不是通用默认，也不是任意新 P/N 对的验证数据集或物理准确性证明。特别是 1.58–1.89 eV 有条件定性范围及 1.98 eV 附近不确定结构均属样品专属审阅结论。代码中的 BN 校准默认值是另一个明确操作策略，不应从这些回顾结果推断。
