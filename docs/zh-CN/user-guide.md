## 工作区与通用控件

正常启动进入原生 Qt Quick 应用。独立的 Peak Analysis、DRR Analysis 和 MCD Organizer 窗口也使用原生 Quick 控件。旧 Widgets 应用仍作为兼容选项保留；启动方法见[开发指南](development.md)。

通过常驻导航栏或工作区标题选择流程。**Controls** 或 **Ctrl+B** 可隐藏能够调整宽度的参数侧栏。并排绘图时，最左侧导航栏自动隐藏以留出空间，参数侧栏仍保留；标题栏继续提供流程选择和导航开关。切换流程会保留各自已加载的数据。返回 PL/DRR 时，图形、缩放/导航状态和光谱叠加均保留。

**View → Appearance** 可选择跟随系统、浅色、深色或高对比度，选择会被记住。窗口、对话框和图形均使用 Arial，导出图中的标题、标签、刻度、图例和注释也相同；数学字符可能回退到符号字体。独立分析窗口和背景窗口遵循相同外观。

PL/DRR 默认使用可拖动的 **70% 热图 / 30% 光谱** 分割。**Hide spectrum / Show spectrum** 位于右下角页脚；光谱标题在坐标轴内部，色条横置于热图上方。PL/DRR、Compare、Power、MCD 和 MCD Peak 的光谱 Y 范围随可见曲线和 X 范围调整。手动 Y 缩放会保留，直到按 **Home** 恢复自动范围。通用绘图工具栏作用于当前流程，包括 Compare。

### 编辑数值

输入绘图/处理数值后，按 **Enter** 或移开焦点提交。标签和单位也在编辑结束后提交。箭头仍可调值；连续修改显示参数会在停止后合并刷新。输入下一个数值时，待执行的绘图刷新或 MCD 重算会等待。Gate/光标仍保持即时交互。

支持小数和科学计数法，例如 `1e3`、`1e-6`、`-2.5e4`，受字段范围和存储精度限制。整数字段仅在计算结果为整数时接受科学计数法。Quick 控件未编辑时省略末尾零：

| 输入类型 | 未编辑时的显示精度 |
| --- | --- |
| 能量范围和分界（eV） | 小数点后 4 位 |
| 峰拟合/手动中心（eV） | 小数点后 6 位 |
| 电压和磁场 | 小数点后 3 位；小容差为 4 位 |
| 温度、波长（nm）、角度 | 小数点后 2 位 |
| 宽度/间距（meV） | 小数点后 3 位 |
| 强度、色限、功率、比值和系数 | 5 位有效数字 |
| 计数、阶数和索引 | 整数 |

小于 `1e-3` 的非零值和绝对值达到 `1e6` 的数使用科学计数法。获得焦点后显示字段完整配置精度，仍可输入更精确的值。格式化不改变计算、范围或导出。旧控件同样压缩未编辑时的文本，并保留自身存储精度和专用 DRR 格式。

色限箭头约取当前最小/最大范围的 0.5%，舍入到 1/2/5 步长，例如 −100…100 使用 1，−0.01…0.01 使用 0.0001。每个产品/区域独立适应 Auto 或恢复视图后的范围。步长不低于字段数值分辨率；上下限相等时参考自身量级，两者为零时参考 0.01。直接输入按控件配置精度提交。

普通滚轮只滚动面板和列表，不改变下拉选项、数字、滑块、旋钮或活动标签。使用点击或键盘编辑。

### 颜色范围滑条

PL 和 DRR 的 **C limits** 位于绘图区下方的固定栏。一、二、三个区域
横向共用一行，每区保留独立双手柄、同步数值读数和 **Auto**。
可编辑的 **Min / Max** 及 **Fix** 放在左栏；拖动时左栏数字立即同步，
不必等待图片刷新。输入数值后按 **Enter** 或离开输入框提交；刷新不会
覆盖尚未提交的草稿，**Escape** 取消草稿。固定端点仍允许手动精确输入。
窗口较窄时滑条横向滚动，不缩小字号或堆叠区域。左栏保留色图、分区边界、
坐标轴及其他显示设置。DRR 的 **Overall / Weak features** 保留在滑条旁，
**Weak strength** 放回左栏。并排显示时，通过产品选择框决定编辑哪张图。
Compare 使用自己的强度分区或 VP 范围；MCD 使用一组地图色限及原有的
整组颜色锁。纯 Spectrum／曲线面板不显示颜色滑条。

非线性滑条在缩小色限后仍保留完整的可编辑数据范围，直接向外拖动即可
查看更大范围，无需切换模式；输入超出当前刻度的合法数值会扩展滑条。
滑条位置与数值不成正比，请参考数值及端点刻度。拖动保留固定端点；
开启零中心且两端均未固定时，对称调整上下限，精确输入仍保留原有语义。
预览以 50 ms 为起始调度目标，按绘制耗时降低频率；松手落实最新范围，
不会排队追赶旧值。大幅规则网格热图在拖动时使用临时低分辨率预览，松手
及导出时使用完整数据。颜色调整不重算 Spectrum 数据或改变选中扫描行。
Show/Hide spectrum 按钮及热图／Spectrum 之间的可拖动分隔线独立保留。

## 查找与加载测量

先选择实验目录，再为相应流程选择数据源。PL 和 DRR 各自维护选择及来源/历史目录，支持最近目录和本地文件拖入。对话框从发起流程的目录打开，不沿用上次打开/保存请求遗留的文件名。

PL/DRR 测量选择器按采集分组，为组和单文件显示 **Unprocessed / Partial / Processed** 状态；筛选或浏览时保留已选文件。搜索支持任意顺序的空格分隔关键词，包括历史及完整文件名，例如 `YZ365 760`。DRR 组摘要显示样品/位置、条件、文件数和状态，组间不同条件优先显示。完整文件名自动换行，提示信息和 Copy filename 保留原路径。

点击或双击可用文件名即可加入，复选框用于切换选择。在已选列表中，双击、按 **Delete** 或使用 **Remove** 移除文件。**Clear all** 清除全部选择，包括被筛选隐藏或不在当前视图的文件。**Selection actions** 提供可选的整组/重复测量加入操作。**Close**、标题栏关闭按钮和 **Escape** 均不改变当前已加载测量。

检查尚在进行时可先显示缓存或仅有文件名的行。整组/重复操作须等待兼容性检查；明确选取的文件可提交，并由加载器验证。仅当设定/实测 Gate 的完整轨迹相同时才合并摘要；实际差异保留。相同的帧数端点只显示一次，例如 **541 frames**。

重新打开时，选择器尽量滚动到最近成功加载的文件及采集组。成功加载更新位置；浏览、取消或加载失败不会替换。主窗口 **Clear** 在同目录、同文件类型下保留浏览位置。搜索/状态筛选继续生效；手动浏览会取消尚未完成的自动定位。

选择实验目录后，PL/DRR 在后台准备目录。采集中，轻量列表仍可使用；自动检查等到来源清单连续三秒不变后再运行，**Refresh** 则立即检查。隐藏选择器仍保留目录监控和待执行检查，不覆盖主窗口加载/导出状态。只有相关来源/结果变化触发刷新，日志及缓存写入不会不断重启扫描。目录探测失败时保留已经验证的列表。

新的 **Load** 会替换排队中的选择，并协作取消过时工作。当前文件读取或数值运算可能完成后才响应取消。**Clear** 和切换实验目录同样使正在加载的请求失效。取消不会恢复旧图或弹出加载失败提示；最新选择失败后也不会转而加载旧队列。导出独立保留已捕获的数据。

## PL

PL 提供单文件热图与光谱、来源/历史搜索、已保存 DAT 选择、坐标派生/自定义 DAT 标签、峰检测和单条光谱 Lorentz 拟合。使用工具栏 Gate 和前后按钮检查实测光谱。支持的输入及 Y 轴选择见[数据与导出](data-and-exports.md)。

### 显示区域与锁定

原生 Display 页面将 **X/Y Min/Max**、各自的 **Fix** 和 **Auto** 放在一起。**Auto 只调整未勾选 Fix 的端点。** 修改数值不会自动启用 Fix。要让锁定端点重新随数据变化，先解除相应 Fix 再 Auto。颜色 Auto 使用可见 X/Y 范围和所选能量区域，Log 只使用正有限值。区域没有可见有限样本，或 Log 没有正值时，保留原色限，Auto 提示不可用原因。

**Linear / Log** 标签同时选择绘图尺度和色限控件。启用 **Side by side** 后两图持续显示，标签仅决定编辑哪套色限。Linear 和 Log 各自保留上下限，包括每个区域端点。新 PL 视图默认色图为 **turbo**，已保存的自定义色图优先。

**Regions** 选择一、二或三个能量区域。Linear/Log 共享分界，但每个区域的色限独立。各区域需要有实测能量列。分界有单独 Fix，可选择显示分界线。改变区域数保留仍可用的现有/共享分界，并初始化新分界；三区分界必须不同且有序。缩放保留实际分界能量，只显示与当前可见范围相交的部分。**Clip outliers** 是独立颜色选项。

无效数值草稿会显示错误并阻止切换颜色标签。请修正，或按 **Escape** 取消草稿，避免把未完成的输入应用到另一套 Linear/Log 色限。

成功保存会在实验目录及导出元数据中记录该文件的显示设置。加载先用默认值，再恢复兼容的该文件设置，随后叠加明确手动锁；其余自动端点随当前数据/可见区域更新。完全兼容的已保存视图保留原色限，直到 Auto 或可见范围实际改变。明确的手动锁定跨文件及重启保留；从文件恢复的锁不会转成全局手动偏好。已保存的 Y 锁保留其兼容的坐标派生/标签上下文。首次保存保留已有处理历史/自动下一项行为。PL 分别导出 Linear/Log PNG，配一份完整网格 DAT，不另提供合并并排 PNG。通用图像宽度设置见[数据与导出](data-and-exports.md)。

## DRR

DRR 支持原生 CSV 自参考/外部参考、预计算 DAT/XLSX 图、能量 SG 导数及混合导数。原生 Display 页面使用公共 `Display.qml` 控件。各区域职责如下：

- **Data** 固定在参数页上方，提供测量选择、当前背景摘要和 **Background…**。
- **Display** 提供坐标和颜色；**More display settings** 包含右 Y 轴、尺度/裁剪选项及显示记忆。
- **Processing** 提供导数/SG 和单光谱拟合；仅混合导数显示 Y 窗口控件。

使用工具栏 **Gate / Previous / Next** 检查相邻实测扫描坐标。**Analysis…** 可将当前已提交来源加入 DRR Analysis，或打开其工作区。主页面即使显示导数，也移交原始已提交来源，避免对已经求导的数据再次求导。

### 推荐显示范围

原生 DRR 底部 **C limits** 栏在每区色限旁提供 **Overall（整体）** 和
**Weak features（弱特征）**，保留原有 **Auto**。整体推荐使用稳健分位数；
弱特征推荐分别估计较平静能量窗口内部的波动，不把窗口间的背景水平变化混入其中；
同时保留一定比例的可见数据，防止少数静区使大部分背景饱和。
先选 **Weak strength** 的 Gentle、Standard、Strong 或 Maximum，
再点击目标区的 **Weak features** 应用。结果显示上下限及饱和点比例。
在数值取整和 Fix 约束之前，四档分别将饱和比例限制在约 20%、40%、60%、75% 以内；
弱特征色限不会超出 Overall 范围，增强档位越高范围不会变宽。
这些是显示启发式规则，不是噪声测量，也不能证明增强的结构是真实信号。
推荐保留 Fix 端点和当前色图，包括 **RdBu_r p=0.60**；线性弱特征推荐关闭
**Center Zero**，Log 模式则使用正值分位数。推荐只改变显示，不平滑、求导或删除数据。

**Trim empty X edges** 根据完整测量图建议裁去左右空白边缘，保留所有扫描行、
色限和现有分区边界，并尊重 X 端点的 Fix；边缘证据不明确时保守保留。
点击 X 旁的 **Auto** 恢复完整范围（固定端点需先解除 Fix）。
裁边不改变分析范围或导出的数值数据；推荐边界不代表其外一定没有弱信号。

### 选择背景

新 CSV 测量先检查已保存背景。没有时自动打开背景设置，不先计算临时 Self 图。取消后测量保留为等待背景状态，使用 **Choose background…** 继续。Reload、返回 DRR 或清空背景都不会静默选择 Self，也不会反复弹窗。有效的已保存参考、明确 Keep 的背景及预计算 DAT/XLSX 可直接加载。缺失/冲突参考需复核；**Reload** 可重试保存参考的恢复。

背景窗口只有一行来源标签：**Self, BN, P, N, P + N, Fitted**，每种分别保留文件和分配方法。Self 提供 **First frame / Last frame**，新草稿默认 Last。改帧只修改草稿，Apply 才计算。新 BN/P/N/P + N 草稿先平均单文件全部帧，再对文件等权平均。**Advanced tools… → Reference frames** 保留明确的首/末帧覆盖选项。不同 Gate 条件的帧不能当作可互换重复。

BN/P/N/P + N 左侧显示可用文件，右侧显示已选参考。**Use files** 选择共用参考或逐测量分配。搜索直接编辑当前来源草稿；增删手势与测量选择器一致。**Show all CSV files** 和 **Browse files…** 可选择其他文件。切换来源标签会保留各自草稿。P、N 生成使用独立单角色选择器，提供 **Use selected / Close**。

**Advanced tools…** 按来源提供 P/N 草稿/版本、拟合、复合编辑、BN 比较及原始预览。**Back to background** 返回时不改变来源类型；已有自定义参考保留原类型和文件，直到明确选择其他来源。**Diagnostics** 打开上次预览报告。详细流程和科学验证见[背景参考](background-reference.md)。

**Apply background** 先验证并试加载完整结果，成功后才更改绘图关联；失败或取消保留之前结果。**Close** 保留已应用参考。应用 **Keep background across groups** 后，共用参考在加载失败/被替换后仍保留，并为每个新组重新验证。自动 BN 比较仍可查看，但不会自动替换 Keep 的参考。

通过 **Load CSV** 或测量选择器打开已处理原始 CSV 时，恢复该精确测量选择最近一次导出的背景，包括帧选择、成员分配、区域参考和拟合设置。明确 Keep 的参考优先。保存参考缺失/不兼容时停止加载并提示复核。普通 Reload 保留随后手动修改的背景。P/N 页的 **Load catalog** 在需要时明确加载采集详情和保存版本。

可选自动 BN 比较在加载后通过可取消后台任务运行，保留明确的原始 BN 选择，只有候选验证及试加载成功才启用。SG 设置改变后重新验证托管候选；没有当前联合证书时恢复实测原始 BN。与当前组、帧和 SG 匹配的报告可直接重开，无需重复比较。导出保留各测量来源及实际拟合分母。

### 产品标签 Auto 与区域

**Display → Colors** 中的 **ΔR/R / Derivative** 标签只选择要编辑的色限，**不会**切换绘图产品。在绘图控件选择 ΔR/R 或 Derivative 时，也选择对应颜色标签。**Side by side** 保留当前颜色标签。每个产品独立保留色图和色限；区域数及 X 分界共享。隐藏控件的值仍用于绘图和成对导出。

上下限及各自 Fix 放在一起。Auto 只改变当前所选产品未锁定的端点。**Auto X/Y/V** 和区域 Auto 保留所有 Fix；取消 Fix 或使用 **Restore Auto for this load** 解除锁定。一/二/三区热图保留每个测量点、独立色限及原始单元边界。

### 记住视图

原生 **Save PNG + DAT** 成功导出会记住 X/Y/色限、一/二/三区、分界、原始/导数色图及范围、Fix 和缩放视口。旧 Widgets 前端的成对 **Save both: PNG + DAT** 及绘图工具栏单独 PNG 保存也会记住这些设置；原生主绘图工具栏没有单独 PNG 保存。同文件/组重载，包括重启后，会恢复最新保存视图。只有成功导出才保存开始导出时捕获的视图，位置为 `Processed Data/DRR/.display_settings.json` 及元数据侧文件，随实验目录移动。

新文件名具有相同波长中心（例如 `720nmc`）时，可复用中心模板的 X 范围/分界。Y/颜色仍自动，除非手动 Fix。换文件时，X 几何优先级为：

1. 明确的 **Lock X range across files**。
2. 目标文件自身快照。
3. 同中心兼容的手动几何。
4. 目标中心模板。
5. Auto。

X 范围、区域数和固定分界一起传递。中心改变后手动 X 几何失效；中心未知时仅同文件重载保留。重载当前文件保留未保存手动编辑。光谱覆盖不兼容则回退 Auto。锁定一条轴不会丢失另一条轴已保存的缩放。

**Display → More display settings** 可关闭同文件/中心记忆、启用可选色限复用或跨实验目录共享中心模板。色限复用和共享默认关闭。**Lock X range across files** 默认也关闭；开启后锁定当前 X 几何和有效分界，包括从预设恢复的值，并跨重启保留。状态文字和 Fix 提示说明当前作用域。

| Fix 标签 | 含义 |
| --- | --- |
| **Fix M** | 手动锁；X 几何通常跟随同波长中心 |
| **Fix λ** | 继承的波长中心模板 |
| **Fix F** | 当前文件已保存显示 |

编辑已锁定值，或将 Fix 取消再勾选，会把继承锁变为手动锁。文件/中心锁超出作用域后失效，不变成应用全局手动默认。有效分界保留；新 X 范围外的分界重新居中但保留 Fix 来源，三区分界围绕有效固定分界依序放置。

手动 **Fix M** 的 Y 和 DR/D2E 各区域端点无需导出即可跨重启保留。固定 Y 保留轴选择及自定义系数；整图 D2E 保留手动颜色模式，直到 Auto。未锁端点跟随下个测量。解除 Fix 会更新重启记忆。**Restore Auto for this load** 释放记忆/手动范围并关闭跨文件 X 锁；**Clear this center template** 保留单文件快照。

原始视图可延后隐藏导数及其自动颜色，直到显示该产品、请求其 Auto 或保存两产品。大图 Auto 在后台运行，初次绘图可能等待颜色，但控件仍可用。过时来源/SG/ROI 结果被丢弃，当前手动锁和编辑受到保留。成对保存同时捕获数据、ROI 和待计算颜色。旧 Widgets 前端的原始图单独 PNG 工具栏保存不会把隐藏导数占位色限当作已保存值。

## Peak Analysis 峰分析

绘制 PL、DRR、Compare intensity 或 Power intensity 后，通过绘图工具栏右侧 **Analyze…** 或 Workflow 菜单打开。英文分析窗口运行于独立进程，使用数值快照。PL 支持检测及可选多峰 Lorentzian/Gaussian 拟合；DRR 支持各已提供产品的峰/谷；Compare/Power intensity 使用 PL 适配器。VP 不适用。重复扫描坐标须明确分离或聚合，不会篡改实测功率来隐藏重复；此类数据仍可使用 Power 自身峰分析。

快照继承色图、色限、对数/零中心归一化及区域色限。DRR 图上方有 **ΔR/R / 2nd derivative** 标签；文件使用另一行标签，单文件仅显示名称。各产品分别保留分支/结果，共享所选扫描坐标。缺失产品须在主应用显示后再发送。同数值数据重新打开会更新显示设置并保留分析；旧保存快照需重新移交才能获得更新的显示元数据。

### DRR：先查找候选，再筛选

新移交的 DRR 默认选择 **All spectra in dataset**，使用完整能量和扫描坐标范围。在 **1 Find candidates** 点击 **Find candidates**，扫描每条光谱的完整能量范围并同时缓存峰和谷。在 **2 Filter results → Keep** 选择 **Peaks only（仅峰）**、**Dips only（仅谷）** 或 **Both（两者）**，然后点击 **Apply filters**；切换类型复用缓存，无须重新检测。若只需检查一行，可在 Spectra 选择 **Current spectrum**。切换分析范围后需要重新查找候选。

新 DRR 数据默认处于 **Auto from data** 模式，candidate floor 为 `0`。查找先建立宽松的候选缓存，再根据实测候选指标生成并应用初始筛选；分析面板显示候选数和保留数。建议值只是启发式起点，不是对物理峰的判定，请结合测量检查和调整。检测在后台运行，支持进度和取消。**Detection settings** 可选择 Off（SciPy `find_peaks`）或 Savitzky–Golay 平滑，并设置窗口及候选下限。原始 ΔR/R 默认使用 11 点 SG；导数产品默认使用局部极值，可选平滑标为 **Extra SG**。SG 不会对传入产品再次求导。修改检测器、SG 窗口或候选下限后须再次点击 **Find candidates**；筛选无法找回下限或平滑阶段遗漏的特征。

在 **2 Filter results** 中设置 **Keep** 保留类型、**Keep range** 范围、预设及质量阈值，然后点击 **Apply filters**。范围和阈值草稿在应用前不会改变结果。筛选复用候选缓存：扩大范围、更改极性或清除阈值后再次应用，即可恢复符合条件的缓存候选，无需重新检测。**Full range**、**Follow plot view** 和 **Custom range** 选择筛选范围；Adjust filters 包含间距、最大宽度/数量和邻行支持。Balanced、Sensitive、Strict 等预设会主动排除部分候选；**All candidates** 和 **Clear quality filters** 可清除质量阈值。检测宽度是半突出程度宽度，与拟合 FWHM 不同。

对于有足够相邻光谱证据的图谱，自动建议会使用同一连续性参考比较七组筛选方案。启发式评分将较弱参考候选的保留率、全部参考候选的保留率、缺少参考连续性候选的去除率分别赋予 45%、25%、30% 的权重；缺少某项证据时，对可用项重新归一化。这个有界参考依据持续、平滑的同极性轨迹，允许每次缺失一行，并在扫描间距较大处中断；它用于评分，不代表物理鉴定或真实标签：噪声也可能连续，真实特征也可能孤立或快速移动。相邻光谱证据不足时（包括单光谱分析），使用统计初始筛选。

检测完成后，**Suggest filters** 可基于缓存候选重新生成并应用建议。手动编辑筛选参数或选择预设后，自动模式不会覆盖这些选择；点击 **Apply filters** 应用手动修改，也可按需再次生成建议。

自动 DRR 分析选定数值筛选条件后，若持续轨迹覆盖至少七条光谱，且占通过质量与邻行支持筛选候选的至少 5%，会启用 **Remove isolated clusters（去除孤立点簇）**。它保护持续轨迹、SNR ≥ 8 或 SNR 不可用的候选，以及局部重复的同类弱特征：七行窗口内至少三个不同扫描行有支持，能量容差依据峰宽确定，并限制为一至三个能量采样间隔。较大扫描间断会打断邻域。这些保护优先保留弱结构，也可能保留相关噪声。单光谱或证据不足时不执行额外清理，**Details** 会显示实际执行情况。关闭 **Adjust filters → Remove isolated clusters** 后点击 **Apply filters** 可恢复这些点；**All candidates** 也会关闭它。已保存的手动选择仍会保留，PL 拟合流程不变。

开启 **Preview excluded points（预览排除点）**，可在热图和当前单谱上查看淡化的 × 标记；只显示最后一次已应用的 X/Y 范围与特征类型内被排除的候选。面板按首个不满足的条件统计数量，包括信噪比、突出程度、宽度、邻行支持、孤立点簇、间距和每谱数量限制。悬停在标记附近，底部光标栏会显示原因；再悬停光标栏可查看详情。参数草稿在点击 **Apply filters** 前不会改变预览，关闭预览也不影响结果。旧保存结果需要重新应用筛选才能生成原因说明。

右栏分为 **1 Find candidates** 和 **2 Filter results**。检测始终缓存峰和谷，**Keep** 只控制筛选保留类型。Find 完成后还会应用自动建议或当前筛选，生成初始预览。选择 **Custom range** 才显示 X/Y 输入框；单光谱分析使用当前选中行。数值质量阈值位于 **Adjust filters**，平滑和候选下限位于 **Detection settings**，自动建议与排除原因的详细说明位于 **Details**；这些区域默认折叠。**Find candidates** 放在检测区，**Apply filters** 固定在底部。

可选的 **Balanced** 筛选预设使用以下起始阈值。突出程度按完整光谱的幅度范围归一化，而不是按所选 X 范围归一化。

| 产品 | 最小 SNR | prominence 比例 | 5 行中的支持数 |
| --- | ---: | ---: | ---: |
| PL、Compare/Power intensity | 5 | 0.05 | 3 |
| DRR ΔR/R | 5 | 0.08 | 3 |
| DRR 二阶/其他明确标记导数 | 7 | 0.10 | 4 |

**Sensitive** 将 SNR 降低 2、prominence 减半、支持数降低 1；**Strict** 将 SNR 增加 2、prominence 乘 1.5、支持数增加 1。Sensitive、Balanced、Strict 的宽度阈值分别为能量中位采样间隔的 2、3、4 倍，同极性间距初值为 2 倍。这些依采样设定的值只是起点，不代表仪器分辨率。

### PL 与共用控件

PL 页面按 **1 Find peaks → 2 Check peaks → 3 Fit → 4 Results** 展开。第一步选择全图或当前谱及分析范围，点击 **Find peaks** 生成候选并应用默认筛选；第二步在图上检查候选，或展开 **Adjust filters** 修改条件后点击 **Apply filters**；第三步选择峰形，点击 **Fit checked peaks**；第四步检查拟合、残差及结果表，再导出。拟合使用已经检查过的候选，不重新找峰或重选筛选条件。步骤可以返回修改，主按钮明确显示下一步。

新 PL 移交默认分析全部光谱、完整能量及扫描坐标范围。PL 拟合使用传入的线性强度，不使用额外平滑后的检测曲线。改变检测参数必须重新找峰；筛选尚未应用时不能拟合、导出或回传旧结果。修改峰形或峰选择只清除旧拟合，不改变候选与筛选参数。已保存工作区保留原有选择。

新 PL 移交默认开启 **Recover weak PL features（恢复弱特征）** 和 **Auto from data**。候选阶段不设相对突出度下限，随后用原始数据减去 SG 检测曲线的局部噪声及相邻光谱证据筛选。**Suggest filters** 比较七组条件，并保护突出且有邻域支持的极大值，避免以删掉主分支为代价选择严格的漂移容差。选择手动预设或修改筛选后，不再自动覆盖参数。切换弱特征模式必须重新 **Find**；旧分析文件保留原模式。

弱特征模式还会按主峰宽度选取三个不同的曲率尺度（中心尺度限制为 5–9 meV，使用其 0.8/1/1.2 倍）。橙色空心菱形表示**待验证肩部位置**，不是已经分辨出的独立峰。其可测突出度记为零；曲率对比度和初值宽度是另列的启发式指标，不是峰高或拟合 FWHM。设置正的最小突出度会排除这些肩部。全图启用邻域筛选时，肩部至少需要五行中四行的支持。原始数据及显示强度不改变。相近分支采用互为最近邻的预测关联，允许配置的短缺行，不补造实测点；较大的扫描坐标间隙会断开追踪。

PL 拟合限制自动峰位漂移，对弱伴峰尝试第二组初值，并在相同实测样本上用全局及局部 BIC 证据比较最多三种单分量删除方案。手动种子不被自动剔除。这是有限的模型比较，不是穷举峰数，也不是物理分峰结论。自动流程每条谱最多拟合八个优先候选，其余保留并明确标为未拟合；超过八个手动或突出种子时需要用户选择。触及边界、肩部位置明显偏移及结构残差均保留复核状态。拟合叠加中的青色圆圈保留检测位置，橙色叉表示未确认的检测位置，分支线显示有效拟合中心。**Show residual** 和当前拟合摘要显示模型局限；CSV/JSON 和 XLSX **Details** 保留来源、质量及暂定候选字段。

在 **2 Check peaks** 中点击热图选择光谱，再点击下方光谱的峰标记选中；橙色竖线表示所选峰。左右拖动修改能量，松开后应用；双击空白处补峰；图表有焦点时按 **Delete** 排除当前峰，按 **Esc** 取消拖动或选点。缩放、平移、计算中或结果尚未更新时不允许图上编辑。也可在 **Edit current spectrum** 输入精确能量并点击 **Update selected peak**。

检查步骤的右栏默认只保留选峰、补峰、删除及下一步。默认位置是初值；展开 **Exact position / constraints** 可输入精确位置、设置宽度和允许移动范围，或勾选 **Fix center at this position**，再点击 **Update selected peak** 应用。修改只作用于当前谱，重新 Find、筛选及保存重载后仍保留；**Reset edits in this spectrum** 恢复当前谱的自动结果。展开 **Whole-map branch selection** 并勾选 **Show all branches** 可排除整条分支。编辑会清除旧拟合，然后前往 **3 Fit** 重新拟合。用户指定峰不被自动删峰比较剔除；固定中心的零标准误表示人为约束，不是测量精度。检查步骤默认给光谱更多高度；手动设置的 Map size 优先。

**4 Results** 区分检测位置、有效拟合中心和其他未确认位置。**Save results** 一起保存作图用 XLSX、主界面导出格式的热图叠图和完整分析 JSON，不再默认生成 CSV。**Save editable session** 保存可继续编辑的工作区；**Show positions in main app** 才会将标记发送到主应用。

可选 **Asymmetric Lorentzian** 只为最强种子分量增加左右宽度差异，其余分量保持对称。它不自动替换默认 Lorentzian；不对称参数限制为 ±0.8，导出的宽度为总 FWHM。降低残差不等于证明弱峰已可靠分辨，仍需检查边界、参数不确定性及结构残差。JSON 保存手动约束、模型、质量指标和编辑记录，默认工作簿仅保留直接用于作图的数值。

图在左侧，操作控件在右侧。**Map size** 将热图占绘图区高度调整为 20%–80%；**Auto** 恢复随分析范围变化的自动布局。该选择按数据集记忆。结果摘要在图旁，**View all results** 打开详细表格。导出需要显式操作；仅点击 **Apply to main app** 才回传主图标记。

启用 **Zoom** 后，拖动可见的黑白矩形框选区域，释放鼠标即可缩放；拖动期间按 **Esc** 可取消本次操作。

新移交默认只显示本次数据集。先前的工作区数据和结果仍会保留，可通过 **More → Show previous datasets** 显示并选择；关闭该选项时返回本次数据。重新打开相同数值数据时保留明确选择的分析范围；旧版隐式 DRR 默认值会更新为新流程。

### 理解检测指标

普通极值的候选宽度是半 prominence 处全宽，不是拟合 FWHM。DRR 和旧 PL 的 SNR 在缓存检测信号的每个有限段上取 prominence/稳健噪声。噪声为去除最长 51 点二阶 SG 基线后残差的 MAD / 0.67448975；这条基线仅用于噪声估计，不移动或重新拟合极值。新 PL 弱特征模式改用最长 101 点局部窗口内“原始信号减 SG 曲线”的残差 MAD，并单独标明肩部对比度。不足七点的段没有噪声估计，启用 SNR 筛选时被排除。SNR 是启发式比值，不是置信概率。

同极性支持在形状/SNR 筛选之后、范围裁剪和分支关联之前，按排序扫描坐标统计。固定预设的基础容差为每邻行 `1.5 meV`，自动筛选会根据数据估计，第二邻行加倍。新建 DRR 全图分析和 **Suggest filters** 会启用 **Adjust filters → Adapt matching to peak width（按峰宽自适应匹配）**：基础容差匹配失败时，宽峰可按两者较小峰宽的四分之一匹配，每邻行最多放宽至基础容差的两倍。新增匹配必须互为最近邻，且次近候选与最近候选的距离差大于基础匹配范围的四分之一。这只为峰位置的少量抖动提供支持，不代表已经连接分支。窄峰、无可用峰宽或基础容差为零时不会额外放宽。关闭开关并点击 **Apply filters**，可恢复固定容差匹配，无需重新检测。保存过的选择会保留；旧分析文件、固定预设、PL 和单光谱分析保持原行为，**All candidates** 会关闭此选项。图边缘按可用行缩减支持要求；大于中位步长 1.5 倍的间隙切断邻域，计数不会递归促进其他点。高支持要求可能缩短分支端点，检查出现/消失处时可降低支持，而不是增加平滑。旧缓存在首次应用预设时补算噪声指标，之后复用。导出/工作区保留原候选池及指标。

### 分支 光谱 拟合与叠加

在 **Branches** 双击改名、勾选纳入或使用 **Exclude branch**。名称/ID/颜色在可逆筛选分裂中保留。**Connect selected branches** 保守连接相邻扫描行缓存位置；歧义点保留为孤立叉，缺行中断连接。**Pick seed** 启用独立手动跟踪流程，使用其间隙/噪声设置。

点击热图或移动 **Spectrum** 检查实测光谱。鼠标读数显示 X/Y 和标签；热图还显示输入网格的 **Z (nearest)**，早于颜色裁剪/归一化或额外平滑。悬停可看信号名/单元坐标。离开图后标记为最后读数，数据/视图改变时清除。对数轴按显示单元边界取样，报告实际扫描值。光谱/残差的 Y 是鼠标位置，不吸附曲线；缺失坐标/Z 为 `—`。鼠标移动仅更新文字，不选择光谱或运行分析。

PL 在 **3 Fit → Fit checked peaks** 拟合，**Show residual** 在已有拟合时显示残差。叠加可选择检测位置或有效拟合中心。**Apply to main app** 将位置发送到匹配的主应用热图。数值来源改变使叠加失效，缩放/色限改变不重跑分析。工具栏 **Size** 调标记面积（默认 `4 pt²`），不重检测、筛选或重建热图，并写入工作区、导出和叠加包。

**Save results** 一次保存 `_peak_results.xlsx`、`_peak_overlay.png` 和 `_analysis_settings.json`；相邻的 **Save figure** 可单独保存叠图。PNG 复用主界面正常热图导出的版式、颜色、标题、色标和尺寸，再叠加筛选后保留的峰/谷标记，不是 Analyze 窗口热图加单光谱的组合。打开分析时捕获主图导出设置；保存时向仍打开的主界面刷新当前实际色标，并校验数值数据仍匹配。主界面不在线时沿用已捕获设置；旧历史缺少可确认的色阶时提示重新从主界面打开，不自动推测色阶。

DRR 在 **2 Filter results → Keep** 选择 **Peaks only / Dips only / Both**，点击 **Apply filters** 后保存。PNG 标记与 XLSX 使用同一份已应用筛选结果，不另设图片专用筛选；被过滤候选点的预览不会进入保存的 PNG。地图上方 **Size** 调整标记面积（默认 4 pt²）。

主图选择宽图倍率（如 2.0×）时，**Save results** 同时保存 1.0× 的 `_peak_overlay.png` 和 `_peak_overlay_2.0x.png`；**Save figure** 同样保存原图和宽图。两张图使用相同数据、色阶及峰/谷标记，宽图仅增加画布宽度，高度、字体大小及 DPI 不变。分析 d2E 时导出的是 d2E 底图和检测结果，不转换成原始 DRR。重复保存及另存为均保留已有文件，使用一致的顺序编号。

XLSX 默认只含可直接作图的数值表：DRR 为 **Peaks** 和 **Dips**；PL 为 **Detected_peaks**，拟合后增加 **Fitted_peaks**、**FWHM**、**Height**、**Area**。每表首列为带单位的扫描坐标，后面为固定分支列；可用的标准误 SE 放在对应数值旁边。无可靠结果处留空，不填零；Area 是拟合分量的全域解析面积。筛选参数、候选点、质量状态、失败原因和编辑记录留在 JSON/分析历史中，不默认追加 Details、Curves、Components 或 Settings 表。

结果直接保存在处理文件所在目录，完整保留原文件名，只把 Unicode 减号等字符规范化为可读 ASCII。重名时 XLSX、PNG、JSON 使用一致的 `_02`、`_03` 编号，不截短名称、不添加哈希或随机 ID。尚未导出的原始数据使用对应 `Processed Data/PL` 或 `Processed Data/DRR` 目录。**More** 中可以另存为或打开保存目录。

分析历史也按处理文件分别保存为同目录下的 `<完整文件名>_analysis_history.npz`；切换文件或关闭时保存当前记录，再次分析时仅加载该文件的历史。旧的合并工作区和旧版嵌套目录保留原件，后台迁移对应记录。`%LOCALAPPDATA%/DPTK/Peak Analysis` 仅用于设置、交接及历史路径绑定/迁移索引和缓存，不再持续追加全局分析工作区。**More → Restart** 先保存再重启。源码/打包代码重启要求见[开发指南](development.md)。

看图时可直接用**滚轮**围绕鼠标位置缩放，**按住中键拖动**平移，**Home** 按钮或键恢复完整范围；**Zoom** 框选仍保留用于精确查看局部。左键仍用于选择光谱和编辑峰位。

## Compare 对比

Compare 有独立原生控件和绘图工作区，支持一致通道分组、手动通道分配、intensity/VP、共享背景校正、独立色限、光谱检查及相应 PNG/DAT 导出，可将 2–4 个所选文件绘制为对比网格。对话框保留发起通道/流程；切换页面保留数据，通用工具栏作用于当前 Compare 工作区。角度参考传给 Power，但两页分别保留已加载数据。

1. 使用 **Select files…**，选择 **Coherent group**，复核 **Auto Detect** 分配。**Manual channel assignments** 可明确指定 KK、KKp、KpK、KpKp 来源；**Swap KK / KKp** 交换前两通道。
2. 选择 **View → Intensity Compare / Valley Polarization**。强度 **Channels** 提供 **KK + KKp**、**KpK + KpKp**、**All four** 或 **Custom**。VP 要求 KK 和 KKp 指定不同来源。
3. 在 **Background and VP** 使用 **Auto constant background**，或关闭后输入 **Constant background**。**Also export VP from KK / KKp** 在该配对可用时附带导出 VP。
4. 调整 X/Y、**Cursor gate**、光谱显示和色限；Intensity/VP 保留不同色限。高级 **Keep bounds on Auto** 可分别锁定端点；**Regional intensity colors** 为强度启用左右独立色限及 X 分界，不作用于 VP。

高级 **Angle rules** 设置旋转输入/输出映射、K/Kp 参考角和容差，**Infer Angles** 协助推导参考。**Source and history filters** 搜索组/文件名并筛选导出状态；**Measured Y axis** 选择 TG/BG/Bias 或自定义线性组合；**Export titles and filenames** 在保存前预览名称。

## Power Dependent 功率依赖

Power 支持单个表头式扫描（`Power_uW`、可选 `stage_pos` 和数值波长/能量列名，每行一档功率），也兼容文件名含 `37.96uW` 等功率的旧序列。`752.5829` 等数值波长表头转换为能量，数据按功率排序。输入详情见[数据与导出](data-and-exports.md)。

### 选择单扫描或配对

打开文件先进入明确选择工作区，再绘图。**Choose Power Group…** 按修改时间从新到旧展示，首批 20 组，**Show older measurements** 展示其他组。每行含标识、日期、通道和功率范围。修改时间只控制排序，不决定配对。**Refresh** 发现新采集并保留视图；搜索/状态筛选保留选择草稿。

单扫描用 **Open sweep**，唯一配对用 **Open comparison**，歧义通道用 **Resolve pairing**。**Details / Adjust pairing** 展示完整文件名及手动分配。**Swap KK ↔ KKp** 交换分配并显示角度。**Open comparison** 将当前组分配保存到可随目录移动的 `.power-selection.json`；Cancel 保留原保存选择，其他组也保持各自分配。

单扫描不需要 KK/KKp 分配；强度对比需要两个不同通道；VP 还要求光谱重叠和有效 stage/功率配对。允许两文件功率网格不同，程序建议兼容配对，也可在详情覆盖。stage 位置重复时不能按 stage 配对，应使用功率插值。打开配对后在页面切换 **Intensity / VP**。

分组优先读取匹配的 `*.experiment.metadata.json`（`files[].path`、`session_id`、`measurement_id`，以及可选样品/位置/温度/Gate）。`channel`、`compare_channel` 或 `polarization` 可标识 KK/KKp。无明确标识时保留文件名上下文。整扫描的偏振 `deg` 字段区分通道，不拆开其他条件相同的测量；run 后缀和其他条件仍属于组标识。Compare/Power 将裸 `deg24`/`deg69` 视为输出/检偏角；唯一旧式配对可在组内推断两个输出参考，靠近配置输出 K 的仍为 K。角度建议采用 Compare 参考。

自动搜索包括 `power_sweep` 等测量子目录；排除 `Initial Data`、旧/归档目录和无光谱的分析 CSV。嵌套合并结果保留在 Processed。**Include filename-based series** 默认关闭；开启后按所在目录分别发现至少两个不同功率的序列，避免普通 PL 文件名挤入默认选择器。通道就绪状态与处理状态分别显示。

### 合并同通道片段

**Combine sweeps…** 合并同一通道的扫描片段。应分别合并 KK、KKp，再将保存结果分配给对比。保存前检查预览中的采集兼容性。

自动设置优先选择能与其他扫描有效直接校准的参考，功率覆盖用于打破并列。校正分别扣背景，再将附加扫描缩放到参考。默认复核显示扫描、倍数和预览；**Advanced settings** 可关闭自动设置，选择参考、无缩放或已知倍数，并编辑背景区间、排除项、重复策略和元数据。

启用缩放时每个输入分别扣背景。默认在公共可编辑能量区间分别取中位背景，初值为公共光谱最高能量的 20%；请选择无信号区间或手动背景。支持输入已知倍数。重叠估计不外推：功率插值只跨相邻且差距在 25% 内的功率，预览光谱实测功率差须在 2% 内。报告配对数、倍数离散和应用同一倍数后的光谱失配。估计倍数离散或光谱失配超过 10% 会拒绝校正、阻止保存，并保留对应扫描/预览。覆盖不足明确标为临时结果。检查饱和，并按显示的从 1 起算功率顺序号排除可疑光谱。

完全相同功率可保留第一、第二扫描或一次平均全部贡献；相近功率仍分别保留。使用第一扫描在公共覆盖内的能量网格，线性插值且不外推。CSV/DAT/JSON 保留来源行和合并策略。禁止重复使用相同原始行，即使输入已改名。

保存组合位于 `Processed Data/Power Dependence/Combined Sweeps`，可在 Processed 直接选择。描述性名称可编辑，来源/设置指纹支持 **Open existing / Create another**。**Back to selection** 保留勾选与复核设置，添加扫描也不丢失。**Save and plot** 打开结果，之后由 **Plot Setup** 控制。名称冲突自动编号，保留已有 CSV。

### 拟合强度与线宽

点击 **Analyze peaks**，或启用 **Peak analysis → Intensity + linewidth vs power**，显示热图、所选光谱拟合/残差、积分强度和 FWHM 趋势。首次分析自动建议最多八个峰并拟合所有实测功率。寻峰对各功率、各通道抽取的光谱分别归一化，减少高功率强峰掩盖低功率弱峰；未分辨峰、噪声、交叉或短暂出现的峰仍需复核。左列是热图/光谱，右列上方强度、下方线宽。默认 **Lorentzian**，也可选 **Gaussian**；在完整实测光谱上以共享线性基线同时拟合全部峰。缩放图像不会缩小拟合能量范围。

需要调整时，使用 **Detect peak guesses**、**Add / Remove**，或切换 **Spectrum clicks → Add peak on click** 在光谱上补峰。选择 **Move selected peak** 后可点击或拖动初值标记，拖动范围限制在相邻峰之间。中心/FWHM 输入是拟合初值，不是测量结果。上述修改先作为草稿，不会每改一项都重拟合；确认标记后点击一次 **Fit all powers** 统一应用，当前分析就绪前不能导出。Peak 1 是最低能峰，趋势标签保持一致。**Advanced fit and display settings** 包含线型、强度指标和独立 Y 轴尺度。积分面积为拟合分量在实测范围内积分（`a.u. eV`）；**Peak height** 使用振幅。

使用 **Issues only** 仅显示异常结果，点击 **Next issue** 逐一检查有问题的实测光谱。**Manual refit selected power** 可改初值、中心界限和模型，预览后只应用当前通道/功率，其余拟合保留。已应用拟合、手动修正、幂律区间和分析显示选择自动保存到本机应用目录；重新打开相同数据后点击 **Analyze peaks** 可直接恢复，不重拟合。数据或背景变化会使旧结果失效；未应用草稿不保存。需要可移动的数值结果和来源记录时，仍使用 Power 结果包导出。

噪声大、未分辨或失败拟合会标记并从趋势排除。点击趋势点检查光谱。**Power Axis: Linear / Log** 同时改变热图和两趋势 X 轴，不重拟合；非正功率仅在对数视图隐藏，导出仍保留。**Color Log** 独立。强度/线宽各自有 Y Log/Linear，默认 Log，导出也遵循；非正 Y 隐藏并提示。稀疏采样仍采用正常单元边界，不人为插白带。标记形状区分来源扫描，颜色区分峰。

拟合后台运行。就绪后，Power 包含 `Power_peak_analysis` CSV、趋势 PNG 和 JSON，记录状态、meV 单位 FWHM、协方差不确定度、中心、强度及来源。KK/KKp 分别拟合，VP 本身不拟合峰。

### 拟合功率律

峰分析或强度图上方的 **Fit power law…** 将积分峰面积拟合为 `I = A P^alpha`，不重算光谱。初选 Peak 1，可任意组合并逐峰拟合。输入/拖动功率界限，默认共享，也可各峰独立；拟合区间与绘图坐标范围互不关联。

对话框显示指数、回归标准误、点数、来源边界警告和可选七点局部斜率图。**Suggest ranges near alpha = 1** 搜索至少六点、半个数量级的宽而稳定区间；无可靠区间时明确说明。建议仅供探索，可手动调整。Apply 显示积分强度拟合叠加。导出在分析 JSON、`_power_law.csv` 和趋势 PNG 中保留区间/结果。回归误差不含增益校准不确定度。使用 Power 流程的导出操作保存分析包。

## SHG Processing 二次谐波

输入含 `measured position`、运动/采集状态及数值波长表头的宽表。SHG 对各角度扣除局部背景，在可设中心波长 ± 半范围内积分；对称背景边带的间隙/宽度可设。可选保守宇宙射线清理在背景拟合前替换窄正尖峰。原始/清理光谱可检查，导出记录去除数量和设置。

两个常驻标签 **Single file** 和 **Compare / Twist** 拟合 `I(theta) = I0 + A cos^2[2(theta-xc)]`。对比独立处理两来源并叠加角度曲线，以明确的 90 度相位折叠/分支选择报告 `twist = (2/3) delta_xc`。控件上方标签支持键盘左右切换。流程保留背景、排除、峰积分、角度拟合、残差和结果表。宽布局显示两种光谱；窄布局提供 **Raw / Corrected** 切换，仍保留角度结果/残差。

**Save XLSX + settings** 写入一份 Origin 友好工作簿及设置 JSON。所有实测角度光谱按波长行/角度列导出，到 Origin 后再选角度。可选 CSV 副本和全波段 cosmic-cleaned 光谱默认关闭，不触发重处理。导出后悬停简短相对结果路径查看完整路径，或用 **Open folder / Copy path**。回执只列一次目录及文件名。工作表、单位和 Origin 操作见[数据与导出](data-and-exports.md)。

## MCD 与 MCD Peak Shift

MCD 加载含数值 `B_T`、角度和波长列的 B 扫描 CSV，配对相反角度帧，扣可选分角度 dark/offset 光谱，并以各角度自身近零场参考归一化。在选定实际 B 下检查原始/校正配对光谱和 MCD 截线。来源、dark 参考及输出目录对话框职责不同；改输出目录保留来源选择。

在 MCD 或 MCD Peak Shift 的 **Data → Select file…** 打开宽文件选择列表。长文件名完整换行，可搜索文件名或文件夹、筛选处理状态；确认或复制完整路径后，点击 **Open selected** 加载。**Browse files…** 将外部 CSV 暂存到同一选择器，取消不会切换当前数据。

漂移选项包括全局增益、逐对 scale/offset，以及限制在非共振区间的稳健线性/二次光谱背景校正。新会话默认全局增益加逐对二次光谱基线。**Select protected regions** 打开反射图，拖动标记每个需保护共振；仅当前 MCD(B) 窗口及启用保护区被排除，足够宽的非保护区变成蓝色背景拟合带。增删、编辑、启停区域立即重算，再使用留出点比较线性/二次模型。手绘区域在重算及重开时保留。

完整 B–能量图与截线共享能量窗口。处理设置短暂合并后自动重算，**Recalculate now** 可重试。MCD(B) 分别处理升/降场分支，提供有符号均值、按场符号的绝对均值及有符号积分。初始只显示 signed mean，也是主要 PNG/设置指标；幅值/积分作为可选诊断，CSV 保留全部列。紧凑导出包含图 PNG/DAT、MCD(B) PNG/CSV、配对诊断及可复现 JSON。

普通 MCD 图上方的 **Peak center (eV)** 显示最多六个推荐积分中心。点击能量按钮即可更新 MCD(B) 积分窗口；Feature catalog 筛选为 Spectrum 或 History 时仍会显示这些推荐。未找到可靠中心时，可手动填写 **Center energy (eV)**。

### 已保存 MCD Extract / Compare

**Open processed MCD Extract / Compare** 浏览保存的 MCD(B)，不重算原始文件。支持掺杂/电场容差、积分能量范围、积分宽度和邻近能量分组，以及逐项纳入/排除。可选自动/明确排序、升降序及调色板。

升场使用实线/实心点，降场虚线/空心点；预览和 PNG 分轴、共用尺度，图例在数据区外。提取产生描述性名称的 Origin 友好 XLSX，含 **Increasing, Decreasing, Slope Summary**，以及 PNG 和设置 JSON。分支表含 X/Y 对、拟合曲线、斜率/截距、点数和 R²。可选分支 CSV 默认关闭。缺失温度先查测量 JSON 或原 CSV，再回退文件名，并记录来源。

### MCD Peak Shift 与 Organizer

MCD Peak Shift 直接复用已接受处理产品，不重新加载，支持原始/导数特征跟踪、实际磁场选择、场拟合、手动特征合并及 CSV/元数据导出。MCD Organizer 独立打开，提供已保存序列对比、能量分组、斜率、Curie-Weiss 拟合、场/温度范围扫描、批量 theta 和科学导出。Tools 提供独立 Organizer 入口。

原生 Peak Shift 保存到 `Processed Data/MCD Peak Shift/<source>_PeakShift/`。相同峰定位、方法和结果身份再次保存时更新原 CSV 和元数据，其他分析并列保留。保存时间写入元数据，已有时间戳文件继续保留。

## Slides 幻灯片

打开 **Slides**，选择要编辑的现有 `.pptx`，然后使用来源/队列/预览工作区。**Insert live** 在桌面 PowerPoint 已打开的同一演示文稿中插入，不保存；**Insert and save** 无论文件是否打开均更新并保存同文件。另存副本是可选操作。

离线生成文件使用随应用提供的 `python-pptx` 库，不要求安装 PowerPoint。实时插入要求 Windows 和桌面 PowerPoint；Windows 发布包已包含 Python 集成桥接。

1. 递归搜索实验 `Processed Data` 下 PNG，按修改时间或名称排序，完整文件名换行。
2. 分别筛选 MCD Combo 图和 MCD(B)，或一键加入同子目录最新匹配的一对。目录徽标/队列警告提示混用 MCD 目录。
3. 按顺序选择，拖动队列调整，逐页预览。
4. 每页可放 1–12 图，包括 8/9/12 图的 2×4、3×3、3×4 布局。
5. 可添加可编辑 PowerPoint 短说明；A/B/C 面板标签默认关闭。不会修改或裁剪来源 PNG。
6. 执行插入。恢复备份及侧文件清单保护演示文稿，并防止同一已保存图重复追加。

## 工具日志与保存

**Tools** 包含运行日志及独立 DRR Analysis/MCD Organizer 入口。旧独立 DRR 工作区仍在 **Tools → Data Organization → Open DRR Analysis**，提供候选检查、历史/比较和峰峰值分析；分析当前图的 Peak Analysis 请用绘图工具栏。

保存成功在状态栏报告完成，并将路径写入 **Log**，保留底部面板可见性和科学文本。**Analysis results** 继续用于找峰/拟合结果。Log 保留最近 300 条纯文本消息，包括多行；滚到底部跟随新消息，阅读旧的保留文本时保持位置。Clear 同时清除已显示及排队消息。加载/导出耗时详情见[开发指南](development.md)。

**Data Maintenance** 只根据验证成功的导出来移动已导出来源 CSV。可选清理仅删除验证过的临时副本，保留规范原始文件；来源/输出变化使回执失效。可使用来源目录刷新/重建及最近目录。在维护实验文件前请读[数据与导出](data-and-exports.md)。

PNG/DAT 宽度、DRR 成对产品、名称冲突、完整数值网格和元数据可移植性见[数据与导出](data-and-exports.md)。**Help → Check for Updates...** 检查稳定更新，是否安装由你决定。[首页](../../README.zh-CN.md)提供 Windows 发行版入口。
