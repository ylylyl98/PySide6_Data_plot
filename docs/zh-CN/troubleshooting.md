## 安装与启动

| 现象 | 检查方法 |
| --- | --- |
| 下载后找不到应用 | 从 [Releases](https://github.com/ylylyl98/PySide6_Data_plot/releases/latest) 下载安装程序或便携 ZIP，而不是源码压缩包。 |
| 移动便携版后无法启动 | 完整解压并保留 `PySide6_Data_Plot` 目录；运行 `PySide6_Data_Plot.exe` 时，旁边应有 `_internal` 和其他附带文件。 |
| Windows 显示 SmartScreen 提示 | 安装包可能未签名。检查下载来源和版本校验文件，不要为排查无关启动错误而关闭系统安全功能。 |
| 源码运行报告导入或依赖错误 | 使用项目虚拟环境，安装 `requirements.txt`；Windows CI 使用 Python 3.13，详见[开发指南](development.md)。 |
| 不同电脑界面或绘图效果不同 | 记录 Windows 版本、显示缩放、主题和图形环境；离屏检查无法验证所有原生 GPU 和字体组合。 |

源码诊断请使用开发指南中的独立检查命令，并使用合成数据和临时设置。
不要把清空应用设置作为第一步：其中可能包含有意设置的手动锁定和已保存选择。

## 查找与加载数据

| 提示或现象 | 检查方法 |
| --- | --- |
| `No CSV files found` | 检查目录、扩展名和工作流筛选条件。常规 CSV 工作流使用实验根目录的工作副本，并非所有选择器都会列出子目录中的采集文件。 |
| `Folder does not exist` / `Selected path is not a folder` | 重新选择目录，尤其是在移动实验目录或断开磁盘后。 |
| 数据源没有出现在列表中 | 检查搜索、筛选和选择范围，再刷新或重新打开选择器；源数据列表与已处理历史列表用途不同。 |
| CSV 无法解析 | 确认表头和数值列符合当前工作流；PL、功率扫描、MCD 和 SHG 并不共用一种通用 CSV 格式。 |
| 已处理 DAT 使用通用坐标名称 | DAT 数值可以在没有元数据时加载；将匹配的元数据文件放在 DAT 旁边，可恢复其中可用的标签与处理信息。 |
| 通道配对存在歧义 | 检查完整文件名与测量条件并显式分配；按修改时间排序并不能确定通道身份。 |

文件约定见[数据与导出](data-and-exports.md)，选择与分组行为见[使用指南](user-guide.md)。

## 显示与数值输入

- **数值看起来被舍入：** 未编辑时会显示简洁文本；聚焦输入框可查看其配置的编辑精度。
  显示格式不会降低科学数据的存储精度。在字段精度和范围允许时，可以输入 `1e-6` 等科学计数法。
- **输入后没有生效：** 按 Enter 或离开输入框，并检查就地错误。
  非有限值、颠倒的上下限或非法 Log 色限会被拒绝，不会悄悄应用。
- **PL 色限标签无法切换：** 修正非法草稿，或按 Escape 取消；合法草稿会在切换前提交。
- **Auto 没有改变某个端点：** 检查该端点的 Fix。Auto 保留固定端点；在 PL 中，两端都固定时，该组 Auto 禁用。
- **Log Auto 没有结果：** 检查当前可见 XY 范围或区域是否有正的有限样本。
  空区域或没有正数样本时保留原值，并显示原因。
- **换文件后仍保留某个设置：** 显式手动锁定可以跨文件及重启生效，文件恢复的锁定和手动锁定优先级不同。
  删除设置前先阅读[显示记忆说明](user-guide.md)。
- **缩放后某个区域不见了：** PL 只绘制物理区域与当前视窗相交的部分；缩放不移动已保存的分界点。
- **图像空白或异常：** 先检查坐标与强度是否为有限数值，再检查源文件、XY 范围、色限及 Log 正数条件，
  然后再决定是否修改处理方法。

## 背景与科学结果

新选择的 DRR CSV 没有已保存背景时，会等待用户选择背景。取消背景窗口不会先计算一个临时 Self 结果。
重新打开背景选择，选取兼容参考并应用草稿。

遇到 `Compute failed` 或背景被拒绝时，检查参考类型、所选文件、帧策略、栅压覆盖和采集条件。
丢失或已改变的背景引用需要明确修复，不应只为得到一张图就改用未经检查的背景。

歧义、文件过期、匹配未解决和验证失败代表不同问题。
[背景与分析参考](background-reference.md)说明了相应检查，以及“数值上可用”和“科学上适合”的区别。
历史实验采用的阈值不能作为另一项测量的通用证据。

## 导出与恢复

| 现象 | 检查方法 |
| --- | --- |
| 找不到导出文件 | 检查 `Processed Data/` 下的工作流目录、所选目的地和完成状态；MCD、SHG、Power 可能创建结果包子目录。 |
| 导出提示路径或写入错误 | 检查磁盘连接、写入权限、路径长度及其他应用是否占用目标；嵌套过深的结果包可能需要更短的实验路径。 |
| 出现多个类似名称的结果 | 重复导出使用防重名后缀或新结果包目录，通过元数据和时间戳识别目标结果。 |
| 加宽 PL 导出有四张 PNG | 倍率大于 1× 时，这是预期行为：Linear、Log 都保留原宽和加宽图片，DAT 仍完整。 |
| DRR 只显示导数却也导出了 ΔR/R | 这是预期行为：ΔR/R 基础结果与导数都会保存。 |
| 移动数据后显示设置未恢复 | 保持 DAT 和对应元数据在一起；按文件索引恢复时还应保留实验目录结构。来源身份与坐标语义必须匹配，不同来源的同名文件不能共用设置。 |
| 导出后工作副本仍在 | 清理是可选功能，还要求 `Initial Data/` 中存在经过验证且匹配的正式原件；失败、已改变或未经验证的导出会保留源文件。 |
| Origin 导入了错误的列 | 选择所需 DAT 或 XLSX 工作表，并按需明确指定 X/Y/Y Error；详见[数据与导出](data-and-exports.md)中的 SHG 和 Origin 说明。 |

失败或已被新请求取代的导出不能当作成功保存状态。
清理文件前，检查完成提示和预期的完整输出文件集合。

## 更新

使用 **Help → Check for Updates…**。应用检查稳定的 GitHub Releases；
源码提交或 Actions 构建产物本身不构成可安装更新。

检查失败时，确认网络可以访问 GitHub 后重试。
新版本如果缺少可用的安装包或校验文件，更新器无法提供经过验证的安装。
校验失败时，不要运行被拒绝的部分下载；请从正式版本重新下载，持续不匹配时反馈问题。

也可以手动打开 [Releases](https://github.com/ylylyl98/PySide6_Data_plot/releases/latest)。
更新已安装应用与拉取源码仓库是不同操作；源码用户应遵循仓库的 Git 同步规则，
不能认为运行安装包会更新自己的源码目录。

## 提供可复现的问题反馈

在 [Issues](https://github.com/ylylyl98/PySide6_Data_plot/issues) 中提供：

1. 应用版本、Windows 版本，以及安装版、便携版或源码运行方式。
2. 工作流、源数据类型和相关处理、显示选项。
3. 最小复现步骤、预期结果和实际结果。
4. 界面上的完整错误，以及相关日志片段或截图。
5. 小型合成或已脱敏的示例，附带必要的元数据文件。

绘图问题请注明 XY 范围、Linear/Log 或 DRR 图像类型、区域数量和 Fix 状态。
导出问题请注明 PNG 布局、输出类型以及操作是否完成。
移除与复现无关的私人路径或测量信息。
