# DRR 绘图对象复用

按用户确认的优先级，拆分测量导数计算、图形对象准备和画布绘制，并实现重复更新的对象复用。此次未增加 External 最终结果缓存或 PNG 独立渲染进程。

## 行为

新模块 `ui_qt/drr_plot_reuse.py` 与 `MainWindow._plot_mode` 集成。源数据对象、产品组合、Figure 尺寸/DPI、网格坐标和轴结构兼容时，复用坐标轴、QuadMesh、色条和谱线，直接更新图像数组、mask、色阶、色图与 linecut。支持 raw、dE、d2E、双图及固定分区边界的分区色阶。

数据来源、产品组合、布局、尺寸、轴范围、log 轴或分区边界变化时回退完整重建。所有产品先验证再修改；更新前失效 blit 背景，避免 gate 操作覆盖回旧图。保留色条格式，清空数据或切换绘图模式时释放复用快照。首次绘图继续完整建立布局。

科学计算仍使用原有异步 SG 导数路径；完整数据与导出精度不变。测试中单图及双图分区更新与强制完整重绘逐像素一致，坐标轴、网格、色条及曲线对象身份保持不变。

## 分阶段测量

脚本：`artifacts/measure_drr_plot_updates.py`。离屏 Qt，分别计时 `apply_sg_derivative_energy`、`_plot_mode` 和 `canvas.draw`；SG window 按 21、23、25、27 更新，polyorder=2。首个窗口排除于重复更新中位数。主动缓存计算结果后测绘图，避免将后台排队等待误算为图形构建时间。数值为三次连续更新的样本中位数，不是长期性能保证。

合成 157×1340 数据：

| 阶段 | 改前 | 对象复用 |
|---|---:|---:|
| 导数计算 | 约 5 ms | 约 7 ms |
| 图形对象更新 | 65 ms | 14 ms |
| 画布绘制 | 185 ms | 157 ms |
| 对象更新 + 绘制 | 250 ms | 171 ms |

另使用 YZ365 最新 raw metadata 记录的 measurement 和完整 2 个背景成员加载真实数据，对比强制完整重绘和对象复用。真实数据导数计算约 0.17–0.26 秒，比合成数据明显更慢，不能用合成计算耗时代表真实数据。

- 完整重绘：重复更新的对象准备 + 画布绘制中位数 **0.276 秒**。
- 对象复用：同一阶段中位数 **0.171 秒**，样本中约减少 **38%**。
- 对象准备单项中位数：**0.090 → 0.022 秒**。
- 首次建图不复用；总 DRR workflow 没有在本次重新计时，不将上述收益套用到首次工作流或导出。

原始记录：`artifacts/drr-plot-updates-before.json`、`artifacts/drr-plot-updates-after.json`、`artifacts/drr-plot-updates-real-full.json`、`artifacts/drr-plot-updates-real-reuse.json`。存在调度和渲染波动；完整重绘与复用分别运行，无磁盘冷缓存处理。
