# DAT / PNG optimization final review — 2026-09-11

**Approve.** Reviewed the two optimization changes in `core/export.py` and the new `tests/test_dat_png_save_optimizations.py`. No blocking correctness or regression issue found. Existing Compare metadata mapping changes in the working tree are outside this review.

DAT still converts each input to a Python float before checking finiteness. `math.isfinite` preserves the prior handling of NaN and both infinities (`nan`), signed zero and finite numbers; `.10g`, headers, transpose, tab separators, UTF-8 and platform newline handling are unchanged. The targeted test includes these special values, numerical extremes and a Unicode header, and ensures the scalar NumPy ufunc is no longer used. Its expected-value generator partly mirrors the implementation; the earlier independently verified production/reference byte comparisons provide complementary evidence.

PNG retains the same renderer, figure dimensions, DPI, FontProperties, text measurement, title wrapping and tight final save. The local Agg implementation's `get_renderer()` creates/caches a renderer using the figure width, height and DPI without requiring a draw. The title helper is called by the shared export figure builder; no caller depends on its previous drawing side effect. Missing/unavailable renderers still use the existing textwrap fallback. Tests compare complete old/new PNG bytes for short/long Unicode titles across three figure sizes, verify zero early draw calls, exercise normal/bold font parameters, and cover missing-renderer fallback. Arbitrary font families are not separately exhaustively tested; the font measurement path itself is unchanged.

Independent reviewer verification on the project `.venv`: `python -m unittest tests.test_dat_png_save_optimizations -v` passed **4/4** (1.767 s test runtime, exit 0). The implementation agent/coordinator additionally reported 59 targeted regressions, compileall, diff checks and six real-data DAT/PNG byte comparisons; those are not represented as newly rerun by this reviewer. Review diff check passed.

No new timing benchmark was run during this final review. Performance evidence remains the earlier equivalent in-process causal experiment in `2026-09-11-dat-png-save-root-cause.md`: full-export CPU 5.047→2.656 s and 3.969→2.797 s, with all 12 DAT/PNG outputs byte-identical. Wall times 9.531→4.573 s and 5.158→5.208 s show that competing machine load can mask the CPU improvement. These historical measurements must not be described as fresh post-implementation timings.
