# Phase 5 Contextual Workbench UX Target

**Status:** Approved and frozen on 2026-09-01.

**Direction:** Phase 2.6 Proposal A — Contextual Workbench.

## Approved design constraints

1. Keep horizontal scientific-workflow navigation.
2. Separate Slides and Tools visually from scientific workflows.
3. Make the sidebar resizable and collapsible, with a target default width of 360–400 px.
4. Keep the plot/canvas as the dominant workspace.
5. Present Data Source as compact, persistent workflow context.
6. Remove file-cleanup and archive actions from the primary command surface.
7. Improve Results and Log discoverability through a coherent bottom-panel model.
8. Separate persistent status, progress/error, and cursor readback.
9. Preserve Slides as a full-width workspace.
10. Preserve scientific behavior, controllers, plotting semantics, compatibility aliases, `objectName` values, accessibility identities, and theme infrastructure.

## Deferred command decision

The exact placement of **Load**, **Plot**, and **Save** is intentionally not approved or frozen. Before placing these commands, Phase 5 must classify each command as global or workflow-contextual and document that decision.

## Scope note

This document records the target UX direction only. It does not authorize implementation or other code changes.
